## 1. UNIT ECONOMICS

### 1.1. Базовые метрики (прогноз на основе данных)

| Метрика | Значение | Обоснование из данных |
|---------|---------|----------------------|
| **CAC (органический, YouTube)** | 50-150 руб. | 912K просмотров на 2 видео одного канала; блогер-партнерство = главный канал. Модель: "Я не могу ответить каждому -- попробуйте LLCAR" (инсайт I-10). Конверсия видео->установка ~2-5% |
| **CAC (платный, таргет)** | 300-600 руб. | Средний CAC для auto-utility apps в РФ. Конкуренция за внимание ниже, чем в e-commerce |
| **CAC (средний, blend)** | 150-300 руб. | При доле органики 60-70% от YouTube и Drive2 |
| **Конверсия install->free active** | 40-50% | CarScanner: бесплатная версия "very powerful" -- высокий engagement. Но барьер: нужен ELM327 для полного функционала |
| **Конверсия free->paid** | 8-15% | CarScanner: конверсия в Pro ~10-15% (одноразовый платеж $5-8). Данные: "Скриншот-просители" -- готовый платящий сегмент (инсайт I-8). Для LLCAR ожидаемо 8-12% на подписку, выше на разовые платежи |
| **ARPU (месяц)** | 250-400 руб. | Blend подписчиков (300-500 руб/мес) + разовые платежи (349 руб за анализ) |
| **ARPPU (месяц)** | 350-500 руб. | Для платящих пользователей |
| **Churn (месячный)** | 15-25% | ВЫСОКИЙ. Причина: 72% респондентов используют приложение ситуационно ("когда что-то случается"). Инф. 12: "через какое-то время забыл бы, что оно существует" |
| **LTV (подписка)** | 1 400-3 000 руб. | При среднем сроке жизни 4-6 мес и ARPU 350 руб. Формула: 350 / 0.20 churn = 1 750 руб |
| **LTV (разовые платежи)** | 500-1 500 руб. | 1-3 разовых использования за жизненный цикл |
| **LTV/CAC** | 3.5-10x | При органическом привлечении: 1750/150 = 11.7x. При платном: 1750/450 = 3.9x |

### 1.2. Ключевые риски Unit Economics

1. **Высокий churn** -- главная проблема. Данные однозначны: LLCAR воспринимается как "разовый инструмент" (подробнее в п.6)
2. **Барьер входа: ELM327** -- нужен адаптер за 1 500 руб. Снижает конверсию install->active. Решение: OCR скриншотов CarScanner (нулевой барьер)
3. **Сезонность** -- использование пиковое весной/осенью, минимальное летом (подробнее в п.9)

### 2.2. Статистика WTP

| Параметр | Значение |
|----------|---------|
| **Медиана WTP** | ~400-500 руб./мес или разово |
| **Q1 (25-й перцентиль)** | 0-200 руб. (скептики + не-ЦА) |
| **Q3 (75-й перцентиль)** | 800-1 500 руб./мес |
| **Максимум (ЦА)** | 5 000 руб./мес (Ахмед, сравнивает с диагностикой СТО) |
| **Выброс** | 15 000-20 000 руб. разово (Нина, сравнивает с StarLine) |
| **Доля "0 руб."** | 9/35 = 26% (не целевые + категорические скептики) |
| **Доля "готовы платить"** | 20/35 = 57% |
| **Доля "условно готовы"** | 6/35 = 17% |

### 2.3. Что влияет на WTP

**Повышает WTP:**
1. Опыт обмана в СТО (+50-100% к базе) -- "зарядили 20 тыс, а деталь стоит 5"
2. Старый б/у автомобиль (+30-50%) -- больше проблем, больше боли
3. Отсутствие "знакомого мастера" (+40%) -- одинокие девушки-водители
4. Сравнение с ценой диагностики в СТО (якорь 3 000 руб.)
5. Провинция -- нет доступа к качественным специалистам

**Снижает WTP:**
1. Наличие знакомого мастера/папы/мужа (-70-100%)
2. Новый автомобиль на гарантии (-80-100%)
3. Технические знания (эксперты, механики) (-60-80%)
4. Низкая частота использования -- "раз в полгода"
5. Наличие бесплатных альтернатив (YouTube, Drive2, форумы)

- Полный анализ скриншота CarScanner: 349 руб
- Предрейсовый чек-ап: 499 руб
- Разбор сметы СТО (Second Opinion): 499 руб
- Сертификат при продаже авто: 999 руб

ПОДПИСКА PRO (для регулярных пользователей):
- 399 руб/мес или 2 990 руб/год (экономия 38%)
- Безлимитные анализы
- История диагнозов + трекинг трендов
- Напоминания о ТО

**Обоснование:**

- Подписка -- для тех, кто видит постоянную ценность (регулярный мониторинг, старые авто, дальнобойщики)
- 2 990 руб/год = ниже якоря "одна диагностика в СТО = 3 000 руб"

## 4. PAYWALL: ГДЕ ИМЕННО СТАВИТЬ ГРАНИЦУ FREE/PAID

### 4.1. Принцип: "Покажи ценность -- ПОТОМ проси деньги"

Данные категоричны: "Пока не понимаю ценности, не могу ответить на этот вопрос" (инф. 28). "Нужно сначала попробовать тест-драйв режима" (инф. 20). Paywall должен стоять ПОСЛЕ демонстрации ценности, но ПЕРЕД полным решением.

### 4.2. Конкретные экраны

```
ЭКРАН 1: ОНБОРДИНГ (FREE)
- "Какая машина? Двигатель? Евро-2? ГБО? Кат удален?"
- Нулевой барьер -> вовлечение

ЭКРАН 2: СКАНИРОВАНИЕ / ЗАГРУЗКА СКРИНШОТА (FREE)
- Подключение через ELM327 ИЛИ загрузка скриншота CarScanner
- Пользователь видит: коды ошибок + цветовой светофор
- "Безопасно ли ехать: ДА / НЕТ" -- бесплатно

ЭКРАН 3: КРАТКИЙ РЕЗУЛЬТАТ (FREE)
- 3 строки: "Найдено 2 проблемы. Одна критичная."
- Светофор общего состояния
- "У 60% владельцев вашей модели такие же показатели -- все ОК"
>>> ЗДЕСЬ PAYWALL <<<

ЭКРАН 4: ПОЛНЫЙ ДИАГНОЗ (PAID -- 349 руб или подписка)
- Расшифровка каждой ошибки на человеческом языке
- "Для вашего Z18XER это значит..."
- Маршрутная карта ремонта (от бесплатного к дорогому)
- Стоимость запчастей + ссылки
- Эталонные значения ("норма для вашего двигателя")
- "СТОП -- проверь сначала крышку маслозаливной (бесплатно)"

ЭКРАН 5: PDF-ОТЧЕТ (PAID -- подписка)
- Shareable отчет для СТО
- "ТО-ЩИТ" -- чек-лист для визита в сервис
- Сертификат при продаже авто

ЭКРАН 6: ИСТОРИЯ + ТРЕНДЫ (PAID -- подписка)
- Динамика параметров во времени
- Прогноз: "Через 10 000 км потребуется..."
- Напоминания о ТО
```

### 4.3. Почему именно здесь

- **Бесплатный светофор** = "конверсия в доверие важнее конверсии в продажу" (инсайт I-3). 60% пользователей увидят "зеленый -- расслабься", и ЭТО станет причиной возврата
- **Paywall после короткого результата** = пользователь уже вовлечен (потратил время на онбординг + сканирование), видит, что проблемы есть, и хочет знать больше. Классический "aha moment -> paywall"
- **Не ставить paywall на "Безопасно ли ехать"** -- это вопрос безопасности. Если скрыть -- потеряем доверие навсегда

### 5.2. Механизмы upsell

1. **Ограничение бесплатных анализов** -- 1 бесплатный, далее 349 руб или подписка
2. **"Экономия X руб"** -- после каждого платного анализа показывать: "Этот отчет сэкономил вам до Y руб на СТО"
3. **Предрейсовые push-уведомления** -- "Через 3 дня длинные выходные. Проверь машину перед поездкой (499 руб)"
4. **"Пора на ТО"** (подписка) -- напоминания привязаны к пробегу/дате, триггер для апгрейда
5. **Shareable-отчет** -- бесплатный краткий (3 строки), полный PDF -- только подписка. Виральность + монетизация

## 6. RETENTION: ПРОБЛЕМА "РАЗОВОГО ИНСТРУМЕНТА"

### 6.1. Диагноз проблемы

Данные КРИЧАТ о проблеме retention:

- Инф. 12: "Через какое-то время забыл бы, что оно существует. И пользовался бы им только когда что-то случается"
- Инф. 4: Готова платить 500 руб/мес, но использует "раз в полгода"
- Инф. 3: "Раз в полгода, когда ломается"
- Инф. 29: "Не настолько часто прибегаешь" -- не готов за подписку
- Гипотеза 5 (подтверждена частично): "Регулярное использование возможно ТОЛЬКО если воспринимается как инструмент профилактики"

**Средняя частота использования по данным: 2-6 раз в год.**

Это означает: классическая подписочная модель НЕ будет основой revenue. Нужно либо (а) увеличить частоту использования, либо (б) адаптировать модель под реальное поведение.

### 6.2. Стратегия решения: "От скорой помощи к диспансеризации"

**Уровень 1: Увеличение частоты (краткосрочно)**

| Механизм | Что делает | Частота |
|----------|-----------|---------|
| **Напоминания о ТО по пробегу** | "Пора заменить масло через 1 200 км" | 1-2 раза/мес |
| **Сезонные уведомления** | "Пора менять резину" (с учетом погоды, не календаря) | 4-6 раз/год |
| **Еженедельный "пульс" авто** | Короткий скан: "Ваша машина в порядке" (30 сек) | 4 раза/мес |
| **Калькулятор потерь обновляется** | "За этот месяц ваша неисправность стоила 3 200 руб" | 1 раз/мес |

**Уровень 2: Социальная вовлеченность (среднесрочно)**

| Механизм | Что делает | Обоснование |
|----------|-----------|-------------|
| **Комьюнити по маркам** | Чат/лента по моделям (как Drive2, но внутри приложения) | Инф. 25: "Социальный элемент -- как Strava для авто". Инф. 19: "Форум нивоводов" |
| **Бортжурнал** | История обслуживания + заметки | 8 из 12 информантов (батч 13-24) хотят напоминания о ТО/расходниках |
| **Сравнение с другими** | "У владельцев такой же Астры средний Health Score 78. У вас -- 85" | Геймификация + engagement |

**Уровень 3: Lock-in через данные (долгосрочно)**

| Механизм | Что делает |
|----------|-----------|
| **История диагнозов** | Чем дольше пользуешься -- тем ценнее история (невозможно перенести к конкуренту) |
| **Тренды деградации** | "За последние 6 месяцев ваша коррекция выросла с +3% до +8%. Рекомендуем проверить ДМРВ" |
| **Прогноз расходов** | "В следующие 6 месяцев ожидаемые расходы: 12 000 руб (масло, колодки, антифриз)" |
| **Цифровой паспорт авто** | Все данные в одном месте -- при продаже = сертификат |

## 7. B2B ВОЗМОЖНОСТИ

### 7.1. Сегменты B2B (по данным исследования)

| Сегмент | Потребность | WTP | Обоснование |
|---------|------------|-----|-------------|
| **Грузовые перевозчики** | Пошаговые мануалы для полевого ремонта (Shaanxi X3000/X5000/X6000) | Высокая (5 000-20 000 руб/мес на парк) | Инф. 24 (Олег): "Сделать для грузовых. Водитель встанет, возьмет монтировку и полезет делать." Единственный респондент, назвавший конкретную нишу B2B |
| **Автопарки (такси, доставка)** | Мониторинг состояния парка, предиктивное ТО, снижение простоев | Высокая (1 000-3 000 руб/авто/мес) | Инф. 32: "Дальнобойщики и фирмы -- готовы огромные деньги отдавать." Health Score по парку = dashboard для менеджера |
| **Независимые СТО** | Инструмент для мастеров + генерация клиентов | Средняя (3 000-10 000 руб/мес) | Инф. 29: "Для автосервисов подписка уместна." Реферальная модель: LLCAR рекомендует проверенные сервисы |
| **Каршеринг** | Автоматическая диагностика между арендами, предотвращение поломок | Высокая (500-1 500 руб/авто/мес) | Инф. 9, 28: опыт каршеринга. Проблемы обнаруживаются во время аренды -- негатив для бренда |
| **Дилеры (б/у авто)** | Сертификация подержанных авто при продаже | Средняя (500-2 000 руб/авто) | Незанятая ниша "Carfax для СНГ". Повышает доверие к продавцу |
| **Страховые компании** | Снижение убыточности через превентивную диагностику | Высокая (пилот) | Инф.: "Готов платить только как дополнение к страховке." Интеграция с КАСКО |

### 7.2. Приоритизация B2B

1. **Грузовые перевозчики** -- самый четкий сигнал из данных, конкретный запрос, высокий WTP, мало конкурентов
2. **Дилеры б/у авто** -- масштабируемо, разовый платеж за сертификат, виральность
3. **Автопарки/каршеринг** -- рекуррентный доход, но требует API + интеграции
4. **Независимые СТО** -- реферальная модель, двусторонний маркетплейс
5. **Страховые** -- долгий цикл продажи, но самый высокий потенциальный чек

**Ключевой инсайт из данных:** "Адаптер -- главный источник проблем, а не приложение" (тезис 5, CarScanner). "Все что дешевле 900 руб не будет работать" (KOLTY, Telegram). Плохой адаптер = плохой опыт = вина ложится на LLCAR.

### 8.2. Бандл-предложения

```
БАНДЛ "СТАРТ" (максимальная конверсия):
- ELM327 Vlinker MC+ (проверенный, рекомендован разработчиком CarScanner)
- LLCAR PRO на 3 месяца
- Цена: 3 490 руб (адаптер ~2000 + подписка ~1200)
- Скидка: ~20% от покупки по отдельности
- Маржа: 30-40%

БАНДЛ "КОНТРОЛЬ" (высокий чек):
- OBDLink CX (лучший адаптер)
- LLCAR PRO на 12 месяцев
- PDF-сертификат при продаже авто (1 шт)
- Цена: 7 990 руб
- Для кого: EV-владельцы, продвинутые

БАНДЛ "ПОКУПКА АВТО" (ситуационный):
- Аренда адаптера на 24 часа (партнерство с пунктами выдачи)
- 1 полный анализ
- Сертификат для покупателя
- Цена: 999 руб
```

### 8.3. Почему бандл критичен

1. **Устраняет главный барьер** -- "мне нужно покупать адаптер?" Ответ: "Все в одной коробке"
2. **Контролирует качество** -- никаких дешевых клонов, которые портят опыт
3. **Увеличивает LTV** -- адаптер = lock-in (физический якорь), подписка продолжается
4. **Маржа на железе** -- дополнительный поток дохода
5. CarScanner Pro lifetime = $5-8. LLCAR должен показать, почему подписка стоит больше -- бандл это делает

## 9. СЕЗОННОСТЬ

### 9.1. Паттерны из данных

| Период | Активность | Что происходит | Revenue-влияние |
|--------|-----------|----------------|-----------------|
| **Октябрь-ноябрь** | ПИКОВАЯ | Подготовка к зиме: замена резины, аккумулятор, антифриз. Сезонные ошибки из-за холода. "Пора менять резину" -- напоминание | +40-60% от базы |
| **Март-апрель** | ПИКОВАЯ | Подготовка к лету: смена резины, кондиционер. Выход из зимних повреждений. Покупка б/у авто (весенний пик) | +30-50% от базы |
| **Май-июнь** | Высокая | Дальние поездки: "предрейсовый чек-ап" перед отпуском. Инф. 21: "Ровно на дальнее расстояние оно и нужнее всего" | +20-30% от базы |
| **Июль-август** | Средняя | Поездки продолжаются, но новых проблем меньше. "В лесу/на трассе без связи" -- офлайн критичен | Базовая |

| **Сентябрь** | Средняя-низкая | "Мертвый сезон" перед осенним пиком | -10-20% от базы |

### 9.2. Сезонные churn-паттерны

- **Churn выше летом** -- проблемы решены весной, машина "работает", зачем платить?

- **Антидот:** годовая подписка (фиксирует пользователя вне зависимости от сезона), оплата сразу за год

## ИТОГОВЫЕ РЕКОМЕНДАЦИИ ДИРЕКТОРА ПО ПРОДАЖАМ

### Приоритет 1: Быстрый revenue (0-6 мес)
1. **Pay-per-use за 349 руб** -- анализ скриншота CarScanner. Нулевой барьер входа. Моментальная монетизация YouTube-аудитории
2. **YouTube-партнерства** -- Opel Garage, АвтоСовет Юрича, IAmCarHacker. Модель: блогер направляет "скриншот-просителей" в LLCAR
3. **Бандл "Старт"** -- адаптер + 3 мес подписки за 3 490 руб. Продажа через Ozon/Wildberries

### Приоритет 2: Рекуррентный доход (6-12 мес)
4. **Годовая подписка за 2 990 руб** -- позиционирование "дешевле одной диагностики в СТО"
5. **Retention-механизмы** -- напоминания о ТО, еженедельный "пульс", калькулятор потерь
6. **Сертификат при продаже б/у** за 999 руб -- вирусный рост, каждый сертификат = реклама

### Приоритет 3: Масштаб (12-24 мес)
7. **B2B для грузовых** -- пилот с 1-2 перевозчиками (Shaanxi, КамАЗ)
8. **Маркетплейс проверенных СТО** -- двусторонняя платформа, комиссия
9. **Международный рынок** -- Украина, Казахстан (идентичная ЦА, тот же язык, те же машины)

### Чего НЕ делать
- Не делать "еще один CarScanner" -- интерпретация, а не сканирование
- Не начинать с B2B -- сначала product-market fit на B2C
- Не фокусироваться на экспертах/механиках -- они не заплатят (6% аудитории, 0 WTP)
- Не запускать подписку без бесплатного уровня -- потеря 50%+ воронки
- Не обещать "заменить автосервис" -- отпугивает (инф. 8: "Меня бы напугали такие фразы")
