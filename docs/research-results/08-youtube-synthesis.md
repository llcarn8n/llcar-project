**Онбординг МЕНЯЕТСЯ:** Первый экран не "подключите ELM327", а: "Какой у вас сканер? Какая машина? Какой двигатель? Удален ли катализатор? Прошивка Евро-2? ГБО?" + импорт скриншота из CarScanner (OCR + LLM).

## 2. ТОП-15 ИНСАЙТОВ

### [#1] 80% вопросов = "моя коррекция X%, это нормально?" — P0
- Подтверждение: ОБА синтеза, ALL 8 агентов. Видео 1: >40 комментариев. Видео 2: 80%+ GAP MAP
- Применение: Светофор коррекции — фича №1. Зеленый/желтый/красный с одной фразой. Первый экран после подключения. Должен УСПОКАИВАТЬ в 60%+ случаев

### [#2] Аудитория уже имеет ELM327+CarScanner — нужна интерпретация, не сканирование — P0
- ~70% упоминают сканер, CarScanner напрямую 4+ раз
- Маркетинг: "У вас уже есть данные. Мы расскажем, что они значат." Импорт из CarScanner/Torque — критичная фича

### [#3] Недоверие к СТО — системная боль — P0
- "6 лет мучаюсь по диагностам", "260 000 руб. впустую", "ЭЛМ на зло СТО" (115 лайков). 70%+ аудитории не доверяют или разочарованы
- Позиция "адвокат владельца" — задокументированная потребность. PDF-отчет "для контроля СТО" — одна из платных фич

### [#4] Замена деталей вслепую — массовый финансовый убыток — P0
- 260 000 руб. впустую (@Xterfort). СТО навязал 6 компонентов — причина в щупе. Продал машину из-за проблемы за 3000 руб.
- "Маршрутная карта ремонта" — приоритизированный чеклист от бесплатного к дорогому. "НЕ МЕНЯЙ лямбду — сначала проверь крышку маслозаливной (бесплатно)"

### [#5] Запрос эталонных значений — "покажите здоровую машину" — P0

### [#6] Клапан адсорбера — причина №1 минусовой коррекции — P1
- 8+ упоминаний автором, множественные кейсы решений
- Первая строка дерева при минусе: адсорбер -> ДМРВ -> лямбда -> форсунки

### [#7] Подсос воздуха — причина №1 плюсовой коррекции — P1
- Крышка маслозаливной = +37% коррекции
- Мастер "Диагностика подсоса": крышка горловины -> щуп -> дроссель -> мембрана КВКГ -> дымогенератор

### [#8] Прошивка Евро-2 / удаленный катализатор сдвигают "ноль" — P0
- 12+ комментариев, "камень с души снял" при осознании
- Обязательный вопрос при онбординге. Коррекция базовой линии: -5...-10% = новый "ноль" для таких машин. Без этого LLCAR даст ложные тревоги

## 3. ПОРТРЕТ АУДИТОРИИ

### "Вооруженный, но не обученный" — единый образ на 2 256 комментариях

**Кто:** Мужчина 30-50 лет, владелец бюджетного автомобиля 8-18 лет (Opel Astra/Zafira, Chevrolet Cruze/Lacetti, Lada Granta/Priora, Renault Logan/Megane, Ford Focus, Hyundai Solaris). Пробег 120-250 тыс. км. Машина вне гарантии. Россия, Украина, Казахстан, Беларусь — часто провинция.

**Инструменты:** ELM327 Bluetooth (~1500 руб.), CarScanner Pro или Torque Pro (~300-500 руб.), базовый набор гаражных инструментов. Знает индекс двигателя (Z18XER, K4M, F18D4). Посмотрел 5-15 видео на YouTube.

**Что пробовал:** 1-3 визита в СТО (потрачено 3-50К руб.), замена 1-4 деталей наугад, чистка ДМРВ/дросселя, гугление симптомов. Ничего не помогло или помогло частично.

**Что ищет:** Не "что такое коррекция" (уже знает). А: "Коррекция -15% на моем Opel Z18XER с Евро-2 и пробегом 180К — это нормально? Опасно ли ехать? Что проверить ПЕРВЫМ?"

**Готовность платить:**
- 300-500 руб. за конкретный ответ — без колебаний (уже заплатил за CarScanner Pro)
- 200-300 руб./мес подписка — только если видит постоянную ценность
- Барьер: обжегся на оплате без результата

**Как говорит:** "Куда копать?", "Это нормально или нет?", "Безопасно ли ехать?", "Уже 6 лет мучаюсь", "Менял все подряд — не помогает", "Горит Джеки Чан". Тон — гаражный, неформальный.

**Эмоциональная траектория:**
Тревога (чек) -> Надежда (купил ELM327) -> Перегруз (куча цифр) -> СТО/YouTube -> Разочарование -> Перебор деталей -> Отчаяние -> Смирение ("так и езжу")
**LLCAR должен перехватить на стадии "перегруз" — до слива денег.**

**Масштаб:** ~912K просмотров на двух видео. С учетом других каналов — 2-5 млн человек ежегодно в СНГ.

## 5. ДИАГНОСТИЧЕСКАЯ БАЗА ЗНАНИЙ

### 5.1. Таблица интерпретации коррекции топлива (LTFT)

| Значение LTFT | Интерпретация | Что проверить | "Безопасно ли ехать?" |
|---|---|---|---|
| **0 до +-3%** | Абсолютная норма | Ничего | Да, без ограничений |
| **+-3 до +-5%** | Норма. Паника необоснована | Мониторить | Да, без ограничений |
| **+-5 до +-7%** | Пограничная зона. В допуске | Мониторить динамику | Да, без ограничений |
| **+-7 до +-10%** | Верхняя граница нормы (GM допуск +-10%) | Адсорбер (минус) / подсос воздуха (плюс), крышка горловины | Да, но запланировать диагностику |
| **+10 до +15%** | Проблема. P0171 вероятна | Подсос: крышка -> щуп -> дроссель -> мембрана КВКГ -> лямбда | Да, но повышенный расход |
| **-10 до -15%** | Проблема. P0172 вероятна | Адсорбер -> ДМРВ (тест отключением) -> лямбда -> форсунки | Да, но свечи заливает |
| **+15 до +25%** | Значительный дефект | Комплексная проверка подсоса + давление топлива + ДМРВ | Осторожно. В СТО на этой неделе |
| **-15 до -25%** | Значительное переобогащение | Адсорбер -> ДМРВ -> лямбда -> форсунки -> давление | Осторожно. В СТО на этой неделе |
| **+25 до +37%** | Критично. Предел компенсации ЭБУ | СНАЧАЛА: крышка горловины(!), щуп. Затем: дымогенератор | НЕТ. В СТО сегодня |
| **-25 до -50%** | Критично | Лямбда-зонд, утечка топлива, ЭБУ | НЕТ. В СТО сегодня |
| **>+37% / <-50%** | Аварийный режим или ошибка датчика | Проверить подключение, лямбда, проводку | НЕЛЬЗЯ ЕХАТЬ |
| **Скачки -100/+87** | Неисправность лямбда-зонда (95%) | Замена лямбда-зонда (только оригинал или Bosch) | НЕЛЬЗЯ ЕХАТЬ |

**Поправки к базовой линии:**
- Прошивка Евро-2 / удаленный кат: сдвиг -5...-10% — новый "ноль"
- ГБО: нормы шире, +-15-20% может быть штатно при неидеальной настройке
- Зима (-30C): сдвиг -3...-5% — сезонная норма
- GM-платформы: допуск шире (+-10%), японцы: допуск уже (+-7%)

## 9. СЛЕПЫЕ ПЯТНА ИССЛЕДОВАНИЯ

### 9.1. Сезонность
Коррекция меняется зимой (-30C -> -4%, норма). LLCAR должен учитывать температуру при интерпретации.

### 9.2. Взаимодействие между параметрами
Граф зависимостей (коррекция <-> лямбда <-> ДМРВ <-> давление <-> адсорбер) не собран. LLCAR может первым показывать СВЯЗИ.

### 9.3. Неисправность БЕЗ ошибок — массовый феномен
ДМРВ "врет", но ошибки нет. Датчик температуры сдвинут на 15, ошибки нет. Суппорт заклинивает, ошибки нет. LLCAR должен анализировать ТРЕНДЫ параметров, а не только DTC. Отсутствие кода ошибки != отсутствие проблемы.

### 9.4. Дизельная аудитория
Все 8 агентов сфокусированы на бензине. CarScanner на дизелях "не показывает коррекции". Целый сегмент с нулевым решением.

### 9.5. Женская аудитория
"Все сервисы обегала" (@Azoygaites), @Евгения-в3з8й (18 лайков). Недообслуженный сегмент, которому СТО навязывают ещё больше.

### 9.6. Эффект "после ремонта стало хуже"
Замена адсорбера -> коррекция -50. Топливная система — связанный граф. LLCAR должен предупреждать: "Замена X может временно ухудшить Y".

### 9.7. Peer-to-peer качество
Часть "народной мудрости" в комментариях ошибочна. Если включать краудсорсинг — нужна модерация.

## 10. KILLER FEATURES — ТРИ ФИЧИ

### Фича 1: "Светофор коррекции" — мгновенная классификация
При подключении: одно число (LTFT) + цветовой индикатор + одна фраза + вердикт "безопасно ли ехать". 80% комментариев = вопрос "это нормально?" Светофор отвечает за 3 секунды. В 60%+ случаев — "расслабься, норма". ALL 8 агентов назвали фичей №1.

### Фича 2: "Маршрутная карта ремонта" — приоритизированный чеклист
Пошаговый чеклист для конкретного двигателя: от бесплатного (крышка горловины, щуп) к платному (ДМРВ, лямбда). С галочками "я уже это проверил". С ценами: "Замена адсорбера: ~2000 руб. vs Перерасход: ~3000 руб./мес". ALL 8 агентов зафиксировали "слепой перебор".

### Фича 3: "Эталон для вашего двигателя" — сравнение с нормой
Рядом с каждым параметром — столбец "Норма для [ваш двигатель]". "Для Z18XER: ДМРВ на ХХ = 2.5-3.0 г/с. У вас: 4.1 — ЗАВЫШЕНО." С учетом модификаций (Евро-2, ГБО). Запрос "скрины исправного авто" — 18 лайков. ALL 8 агентов.
