### ⚡ ТОП-15 ИНСАЙТОВ (по приоритету)

[I-1] H1 Trust Gap подтверждён из 5 независимых источников — P0
Что: Пользователи используют OBD2-данные не для настройки, а для второго мнения перед сервисом — чтобы не быть обманутыми.
- Reviews: *«Car Scanner показал P0420, но расшифровки не дал — пришлось искать в интернете»*
- Reddit: *«In the spirit of 'trust but verify' I purchased an OBD2 plug»* (Score: 96)
- 4PDA: *«CarScanner показал состояние катализатора 1.1. Поехал к спецам — катализатор рассыпался»*
- YouTube comments: 70%+ аудитории не доверяет СТО. «ЭЛМ должен быть на зло СТО в каждой машине» (115 лайков)
- YouTube comments: Кейс @Xterfort — 260 000 руб. потрачено впустую. Кейс @александр: СТО навязал 6 компонентов, причиной был подсос через щуп
- YouTube overview: ниша «защита от СТО» полностью свободна — ни одного видео ни у одного конкурента
Для LLCAR: Позиция «адвокат владельца» — не маркетинговая гипотеза, а задокументированная потребность. PDF-отчёт «для контроля СТО» — одна из платных фич. Тон во всём продукте: «мы на вашей стороне».
[I-2] Объяснение важнее данных. Gap интерпретации = core value — P0
Что: Главный unmet need — не получить данные (CarScanner делает хорошо), а понять, что они означают.
- YouTube: 80%+ комментариев = вопрос «моя коррекция X%, это нормально?»
- YouTube: «Есть у меня OBDII, но смотрю на эту кучу цифр, а понять ничего не могу»
- Forums: «SOC difference on Dash vs Car Scanner» — видит 2 числа, не знает кому верить
- Reviews: «расшифровки ошибок пришлось искать в интернете» — топ-боль
- 4 независимых агента YouTube пришли к этому выводу независимо
Для LLCAR: Каждый параметр → светофор (зелёный/жёлтый/красный) + объяснение на человеческом языке + «Безопасно ли ехать?». Это и есть Health Score на практике.
[I-3] Светофор нормы — фича #1. LLCAR должен успокаивать в 60% случаев — P0
Что: Порог ±10% — допустимая норма. Люди паникуют при 3-7%, хотя это абсолютно нормальные значения. LLCAR должен прежде всего УСПОКАИВАТЬ.
- YouTube V1: >40 комментариев с вопросом «это нормально?» при значениях 2-7%
- YouTube V2: «порог ±10%» повторяется автором 8+ раз
- 40% аудитории — новички, задающие «это нормально?» при значениях 2-7%
Для LLCAR: Зелёный светофор с фразой «Расслабься — для твоей Астры это норма» = первый экран результатов. Конверсия в доверие важнее конверсии в продажу.
[I-4] «Безопасно ли ехать?» — первая строка на экране результатов — P0
- YouTube: вопрос встречается в обоих видео, 6/8 агентов выделили как критичный
- Нет ни одного приложения, которое отвечает на этот вопрос явно
- Кейсы от -7% (безопасно) до -100% (категорически нет)
Для LLCAR: Индикатор БЕЗОПАСНО / ОСТОРОЖНО / НЕ ЕХАТЬ — не внизу, не за кнопкой — ПЕРВОЕ что видит пользователь после анализа.
[I-5] Евро-2 / ГБО / удалённый кат = обязательный контекст онбординга — P0
Что: Прошивка Евро-2 и удалённый катализатор сдвигают «ноль» коррекции на -5...-10%. ГБО даёт нормы ±15-20%. Без этих данных LLCAR будет генерировать ложные тревоги.
- YouTube: 12+ комментариев, «камень с души снял» когда узнали про сдвиг базовой линии, 7/8 агентов
- ГБО особенно распространено в СНГ — массовый сегмент
Для LLCAR: Обязательные вопросы при онбординге: «Удалён ли катализатор?», «Прошита ли под Евро-2?», «Установлено ли ГБО?». Без этого — точность системы под угрозой. P0 по влиянию на качество.
[I-6] Маршрутная карта ремонта — «СТОП, проверь сначала» — P0
Что: Массовый паттерн — замена деталей вслепую → финансовый убыток. Люди меняют лямбду, не проверив крышку маслозаливной горловины (бесплатно).
- YouTube: 260 000 руб. впустую (@Xterfort); продал машину из-за проблемы за 3000 руб.; СТО навязал 6 компонентов — причина в щупе
- Паттерн «дорогое первым» = норма в СТО
Для LLCAR: Для каждого диагноза — приоритизированный чеклист от бесплатного к дорогому. Фраза: «НЕ МЕНЯЙ лямбду — сначала проверь крышку маслозаливной (бесплатно)». Функция «СТОП — проверь сначала».
[I-7] Эталонные значения — «покажите здоровую машину» — P0
Что: Люди хотят видеть рядом со своими данными нормальные значения для их конкретного двигателя.
- YouTube: скриншот исправного авто — 18 лайков (самый запрашиваемый фичер)
- YouTube: «Скиньте таблицу как должно правильно работать»
- 4 независимых агента выделили как «убийственную фичу»
Для LLCAR: Столбец «Норма для вашего двигателя» рядом с каждым параметром. Не абстрактные проценты, а «для Z18XER норма LTFT на ХХ = ±5%, у вас +7% — пограничная зона». Привязка к марке/модели/двигателю.
[I-8] Скриншот-просители — готовый платящий сегмент — P1
Что: Десятки людей в комментариях YouTube просят эксперта посмотреть их данные. Явно готовы платить.
- YouTube: «Можно вам показатели скинуть. Если что я заплачу»
- YouTube: «Если вам скину скрипт, сможете посмотреть?»
- 5/8 агентов выделили как отдельный поведенческий паттерн
Для LLCAR: MVP-фича: загрузка скриншота CarScanner → OCR → LLM-анализ → заключение за 349 руб. Нулевой барьер входа — не нужен ELM327 в момент покупки. Главный канал конверсии с YouTube.
[I-9] Тон — «друг в гараже», не «врач в клинике» — P1
Что: Аудитория говорит матерком, называет Check Engine «Джеки Чан», ценит «без воды, на пальцах».
- YouTube Synthesis 1: агент D прямо возражает против медицинской метафоры
- YouTube Synthesis 2: гаражная лексика, неформальный тон — норма в комментариях
- Reviews/4PDA: тот же тон
Для LLCAR: Медицинские метафоры — в структуре (Health Score, шкалы, «сертификат»). Гаражный тон — в тексте интерфейса. «Давай разберёмся», не «Диагноз: нарушение топливной адаптации». «Коррекция 7% — расслабься, это норма для твоей Астры» вместо «Значение в допустимых пределах».
[I-10] YouTube-блогеры — главный канал привлечения — P1
Что: 100% выборки YouTube-аудитории пришла с видео. 912K просмотров у двух видео одного канала об одной теме.
Для LLCAR: Партнёрства с автоблогерами-механиками. Модель: блогер говорит «Я не могу ответить каждому — попробуйте LLCAR». LLCAR = масштабируемая версия «ответа эксперта в комментарии». Первый таргет: Opel Garage, Юрич (АвтоСовет), IAmCarHacker.
[I-11] LLCAR и CarScanner — разные аудитории. Не конкурируем напрямую — P1
Что: Ядро CarScanner = VW/Skoda/Audi power users (42% Telegram = адаптер/подключение + кодировка VAG). LLCAR целится в обычного владельца с Check Engine — новичок, который хочет один ответ.
Для LLCAR: Не конкурировать за VAG power users. Позиционирование «надстройка над CarScanner» снимает конфликт и расширяет рынок — не нужно переключать пользователей, нужно дополнять их опыт.
[I-12] Страх «сломать машину» — конверсионный барьер — P1
Что: Массовый страх среди RU аудитории — сканер может навредить машине.
Для LLCAR: Первый экран онбординга: «LLCAR только читает данные. Как термометр — он не меняет ничего в машине.» FAQ на лендинге: «Может ли LLCAR навредить?» — высокоприоритетный контент.
[I-13] Провинция — ядро аудитории, LLCAR = единственный «специалист» — P2
- YouTube: «Для нас в глубинке» — 59 лайков (2-й по популярности комментарий)
- 4/8 агентов выделили как сегмент
Для LLCAR: Маркетинг: «Ваш личный диагност в телефоне — 24/7, без поездки в областной центр». 349 руб. = в 10x дешевле поездки к диагносту в город. Локализация на украинский — low-hanging fruit.
[I-14] Калькулятор потерь — конвертировать боль в рубли — P2
- YouTube: перерасход 1.5 л/100 км = ~3000 руб./мес. Кейс: 48 л/100 км.
- ALL 8 агентов выделили расход как осязаемый симптом
Для LLCAR: «Ваша проблема стоит вам 3400 руб. каждый месяц. Ремонт — 2000 руб.» Калькулятор: коррекция +15% × ваш расход × цена бензина = X руб./мес.
[I-15] Отчёт = социальный объект. Виральность через делимость — P2
Что: Люди публично делятся OBD-данными на форумах для получения второго мнения. Каждый пост = органическая реклама.
Для LLCAR: Красивый shareable отчёт = главный вирусный механизм. Дизайн «хочу показать другу / механику / при продаже авто». Сертификат при продаже авто — незанятая ниша (аналог Carfax в США).

### 👤 ПОРТРЕТ АУДИТОРИИ

«Вооружённый, но не обученный»
Кто: Мужчина 30-50 лет. Бюджетный авто возрастом 8-18 лет (Opel Astra/Zafira, Chevrolet Cruze/Lacetti, Lada Granta/Priora, Renault Logan, Ford Focus, Hyundai Solaris). Пробег 120-250 тыс. км. Машина вне гарантии. Россия/Украина/Казахстан/Беларусь — часто провинция.
Что имеет: ELM327 Bluetooth (~1500 руб.), CarScanner Pro или Torque Pro (~300-500 руб.), базовый гаражный инструмент. Знает индекс двигателя (Z18XER, K4M, F18D4). Посмотрел 5-15 YouTube-видео по своей проблеме.
Что уже пробовал: 1-3 визита в СТО (потрачено 3-50К руб.), замена 1-4 деталей наугад, чистка ДМРВ/дросселя, гугление симптомов. Ничего не помогло или помогло частично.
Что ищет: Не «что такое коррекция» — он знает термин. А: «Коррекция -15% на моём Opel Z18XER с Евро-2 и пробегом 180К — это нормально? Опасно ли ехать? Что проверить ПЕРВЫМ, чтобы не потратить деньги зря?»
Сколько готов платить: 300-500 руб. за конкретный ответ — без колебаний (столько же заплатил за CarScanner Pro). 200-300 руб./мес подписка — только если видит ценность ДО оплаты. Барьер: обжёгся на оплате без результата.
Как говорит: «Куда копать?» «Это нормально или нет?» «Безопасно ли ехать?» «Уже 6 лет мучаюсь.» «Горит Джеки Чан.» Тон гаражный, иногда с матерком.
Тревога (чек) → Надежда (купил ELM327) → Перегруз (куча цифр) → СТО/YouTube → Разочарование → Перебор деталей → Отчаяние → Смирение («так и езжу»)
Масштаб рынка: 912K просмотров на двух видео одного канала об одной теме. С учётом всех каналов и поисковых запросов — 2-5 млн человек ежегодно в СНГ имеют эту боль.

### 4. UX И ДИЗАЙН-СТРАТЕГИЯ

Главный UX-принцип — один
[Designer формулирует как Принцип 1. PM подтверждает через JTBD — пользователи хотят ответ, а не данные. Sales подтверждает через инсайт В: «аудитория готова платить за объяснения, не за сырые данные».]
Каждый датчик = значение + цветовая индикация + одна фраза на человеческом языке. Никаких «30000 на каждый цилиндр» без контекста нормы.
Critical User Journey — от «загорелась лампочка» до «понял что делать»
Шаг 1: Пользователь видит чек-лампу → паника
Шаг 2: Открывает LLCAR → одна кнопка «Провести диагностику»
Шаг 3: 3 иллюстрации: вставь адаптер в разъём → включи зажигание → нажми «Подключить»
Шаг 4: Приложение определяет авто по VIN / предлагает 2-3 варианта (без кодов платформ)
Шаг 5: Progress bar «Читаем данные вашего Toyota Camry 2019»
Шаг 6: Главный экран — Health Score 67/100 + «1 ошибка требует внимания»
Шаг 7: Детализация: «Катализатор теряет эффективность. Это не аварийная ситуация. Замена в течение 1-3 месяцев. Стоимость: 8 000–25 000 руб.»
Шаг 8: CTA: «Сохранить отчёт» / «Поделиться с механиком»
Весь путь: не более 5 минут. Не требует технических знаний. Пользователь знает что делать.
Ключевые экраны MVP
- 3 иллюстрации (вставь / включи / подключи)
- Умный поиск — только BLE-устройства (не путает Classic с BLE)
- Автоопределение авто по VIN с подтверждением
- Индикатор качества адаптера (защита от ELM 2.x подделок)
- Fallback: марка/модель/год — простой список без технических кодов
- Большое число 0-100 с цветом (зелёный / жёлтый / красный)
- Статус одной фразой: «Всё в порядке» / «Есть вопросы» / «Требует внимания»
- Список систем: Двигатель ✓ / Тормоза ✓ / Трансмиссия ⚠ / Электрика ✓
- CTA «Детальный отчёт»
- Код (P0420) — серым, второстепенно
- Название человеческим языком: «Катализатор теряет эффективность» — главное, крупно
- Уровень срочности с объяснением
- Что это означает для владельца (1-2 предложения)
- Что делать: «Можно ездить, заменить в течение 1-3 месяцев»
- Стоимость ремонта: диапазон
- Кнопка «Сбросить ошибку» с предупреждением
- «Диагностика [Марка Модель] [Дата]»
- Health Score + краткое резюме
- Список ошибок с расшифровкой
- Ключевые показатели на момент диагностики
- Кнопка «Отправить механику» / «Поделиться»
- Брендирование LLCAR — каждый шаринг = реклама
- 4-6 датчиков — только самые важные для данного авто (не 50)
- Каждый датчик: значение + шкала с зонами нормы
- CarPlay-версия: 1-2 числа + Health Score (минималистично)
- Показывается первым после подключения, не во время диагностики
- Чёткая таблица Free vs Paid
- Гарантия: «Если не работает с вашей машиной — возврат за 7 дней»
Дизайн-риски которые нельзя допустить
[Designer, подтверждено PM и Sales]
1. «Available in Pro Version» на работающих данных без предупреждения — самый деструктивный антипаттерн Car Scanner, вызывает ощущение «bait and switch»
2. Сырые числа без нормы — пользователь видит «30000» и не знает это норма или катастрофа → уходит, или хуже — принимает неверное решение
3. Более трёх шагов в подключении — каждый дополнительный шаг теряет ~20% пользователей
4. Техническая терминология на главных экранах — PID, MQB, PQ46, ISO 9141-2 не должны появляться на пути нетехнического пользователя
5. Белый экран после оплаты — если PRO активация ломает подключение — немедленная потеря пользователя и 1-звёздный отзыв

### 10. ОДНА СТРАНИЦА ДЛЯ ИНВЕСТОРА

Проблема
Каждый владелец автомобиля в РФ сталкивается с «чеком» или плановым ТО — и оказывается беспомощным перед автосервисом. Он не знает что значит ошибка P0420. Он не знает кому верить. Стоимость диагностики в СТО — 1500-4000₽ за каждое посещение. Рынок вторичных авто требует проверки перед покупкой — и инструмента нет.
Решение
LLCAR («Автомобильный врач») — мобильное приложение, которое читает состояние автомобиля через OBD2-адаптер и переводит технические коды в человеческие ответы с рекомендациями. Health Score 0-100. Стоимость полного отчёта — 349 рублей. Это в 4-10 раз дешевле поездки в СТО.
Рынок
- Car Scanner ELM OBD2 (прямой конкурент): 1M+ скачиваний в RuStore, 93K+ оценок в App Store суммарно — без маркетинга. Это proof of market.
- Рынок вторичных авто в РФ: ~4 млн сделок в год. Pre-purchase inspection — отдельный сегмент.
- FIXD (США): $20 адаптер + $7/мес, 5M+ пользователей — эта модель работает.
- Оценка RU-аудитории активных пользователей OBD2: 2-5M человек (нижняя граница по данным Car Scanner).
Бизнес-модель
- Freemium: бесплатное подключение + Health Score как число
- Tier 1: 349₽ / $5 за разовый полный отчёт с расшифровкой
- Tier 2: 1990₽/год / $25/год — безлимитный мониторинг + история + CarPlay
- Bundle: адаптер + 1 год подписки как физический продукт (через Wildberries/Ozon)
- Phase 2: шаримый «Сертификат здоровья авто» при продаже
Почему мы победим
1. Car Scanner — продукт одного разработчика с грубой поддержкой и непрозрачной монетизацией. Два самых залайканных отзыва в RuStore — призывы не покупать. Альтернативы нет.
2. LLCAR не просто «ещё один OBD2-сканер». Мы занимаем позицию адвоката владельца — никто в мире её не занял в масштабе RU-рынка.
3. Технологическое окно: iOS 26 открыл CarPlay API. Санкции создали платёжный вакуум для конкурентов.
4. Отчёт как вирусный артефакт: каждый шаринг PDF — бесплатная реклама.

### РЕШЕНИЕ #1 — Health Score в бесплатной версии

Принято: Вариант Б с модификацией
Бесплатно показываем Health Score + краткий статус по системам в реальном времени (в моменте подключения).
Без динамики и истории — это платно.
- Health Score 0-100 (число + цвет)
- Статус по системам: Двигатель ✓ / Трансмиссия ⚠ / Электрика ✓ (флаги, без объяснений)
- Список кодов ошибок (сами коды — P0420, без расшифровки)
- Расшифровка DTC на человеческом языке («Катализатор теряет эффективность»)
- «Безопасно ли ехать?» + рекомендация
- История изменений Health Score
- Сравнение «было / стало»
- PDF-отчёт
Логика: пользователь видит что есть проблема (флаг ⚠) и насколько серьёзно (Health Score),
но не знает что именно и что делать — это создаёт мотивацию к оплате без ощущения обмана.

### РЕШЕНИЕ #2 — Основная модель монетизации

Принято: Вариант В — Гибридная модель

**[Таблица 1]**

| Тариф | Цена RU | Цена EN | Суть |
|---|---|---|---|
| Free | 0 | 0 | Подключение + коды + Health Score в моменте + статусы систем |
| Разовый отчёт | 349 ₽ | $5 | Полная расшифровка DTC + «безопасно ли ехать?» + PDF |
| Мониторинг / год | 1 990 ₽ | $25/год | Всё + история + уведомления + CarPlay |
| Мониторинг / мес | 249 ₽/мес | $4/мес | Помесячная версия |

Логика: разовый отчёт = точка входа с низким барьером (H1 — лампочка загорелась).
Подписка = для тех кто хочет следить за состоянием постоянно (H2 — мониторинг).
Два разных сценария — два разных ценовых продукта.

### Следствия этих решений для разработки

Что изменилось в архитектуре продукта
1. Health Score экран — два режима:
- Live (free): подключился → видишь число + флаги систем в реальном времени
- Report (paid): фиксированный снимок с расшифровкой, рекомендациями, PDF
2. История — только для платных. В free — только текущее состояние.
3. DTC экран — в free показывает код серым + иконку замка + «Узнать что значит за 349₽».
Не скрывать сам факт ошибки — только объяснение платное.
4. Конверсионный момент — происходит естественно:
пользователь видит ⚠ на «Двигатель», видит код P0420 → хочет понять → 349₽.
РЕШЕНИЕ #4 — Алгоритм Health Score
Принято: Вариант Б — на основе реальных значений датчиков
Health Score считается по трём слоям:
1. Readiness Monitors (OBD стандарт Mode 01/06) — pass/fail по 8-11 системам
2. Значения ключевых датчиков vs нормативный диапазон по марке/модели
3. DTC-коды (количество + критичность) как дополнительный вес
Следствие: нужна база нормативов по топ-20 маркам до запуска MVP.

### 1. ГЛАВНЫЙ ПИВОТ

Вердикт: УТОЧНЕНИЕ позиционирования, не пивот
Исходная гипотеза «тревожный владелец с горящим чеком» не опровергнута — она недостаточна. Данные показывают, что реальный пользователь находится на 3-5 шагов дальше по воронке:

**[Таблица 1]**

| Наша гипотеза | Реальность (2256 комментариев) |
|---|---|
| Горящий чек → паника | Чек горит уже 2-12 месяцев → хроническая фрустрация |
| Не имеет инструментов | Уже имеет ELM327 + CarScanner/Torque (~70%) |
| Ищет «что не так» | Знает что не так, ищет «что делать и в каком порядке» |

| Новичок | «Вооружённый, но не обученный» — знает термины, не понимает связи |

Позиционирование — МЕНЯЕТСЯ. Не «OBD-II сканер на человеческом языке», а «Интеллектуальный переводчик данных вашего сканера + персональный автодиагност». LLCAR = надстройка над CarScanner, не его замена. Это расширяет рынок: не нужно продавать адаптер, не нужно конкурировать по сбору данных.
Онбординг — МЕНЯЕТСЯ. Первый экран не «подключите ELM327», а: «Какой у вас сканер? Какая машина? Какой двигатель? Удалён ли катализатор? Прошивка Евро-2? ГБО?» — и далее контекстная интерпретация. Дополнительно: импорт скриншота из CarScanner (OCR + LLM) — нулевой барьер входа.
Интеграция с CarScanner — ДА, нужна. Минимум — распознавание скриншотов. Оптимум — прямой импорт данных. CarScanner дополняющий продукт, не конкурент.
Core feature set — УТОЧНЯЕТСЯ. Не «покажи ошибки» (CarScanner уже делает), а: (1) светофор нормы, (2) объяснение на человеческом языке, (3) приоритизированный чеклист «что проверить». DTC-расшифровка — вторичная фича, не первичная.

Что уже пробовал: 1-3 визита в СТО (потрачено 3-50К руб.), замена 1-4 деталей наугад (по совету мастера или YouTube), чистка ДМРВ/дросселя, гугление симптомов. Ничего не помогло или помогло частично.
Что ищет: Не «что такое коррекция» (он уже знает термин). А: «Коррекция -15% на моём Opel Z18XER с Евро-2 и пробегом 180К — это нормально? Опасно ли ехать? Что проверить ПЕРВЫМ, чтобы не потратить деньги зря?»
Сколько готов потратить: 300-500 руб. за конкретный ответ на конкретный вопрос — без колебаний (уже заплатил столько же за CarScanner Pro). 200-300 руб./мес подписка — только если видит постоянную ценность. Барьер: обжёгся на оплате без результата. Ему нужно увидеть ценность ДО оплаты.
Как говорит о своей проблеме: «Куда копать?» «Это нормально или нет?» «Безопасно ли ехать?» «Уже 6 лет мучаюсь», «Менял всё подряд — не помогает», «Горит Джеки Чан». Тон — гаражный, неформальный, иногда с матерком. Ценит «без воды, на пальцах».
Масштаб: ~912K просмотров на двух видео одного канала об одной теме. С учётом других каналов и поисковых запросов — 2-5 млн человек ежегодно в СНГ имеют эту боль.

### 5. KILLER FEATURES — ТРИ ФИЧИ, КОТОРЫЕ СДЕЛАЮТ LLCAR НЕЗАМЕНИМЫМ

Фича 1: «Светофор коррекции» — мгновенная классификация
Что: При подключении к OBD-II (или загрузке скриншота) пользователь видит: одно число (LTFT), цветовой индикатор (зелёный/жёлтый/красный), одну фразу на человеческом языке, вердикт «безопасно ли ехать».
Почему закрывает 80%: 80% комментариев = вопрос «это нормально?». Светофор отвечает за 3 секунды. В 60%+ случаев ответ — «расслабься, это норма» — и человек УСПОКОЕН. Для остальных 40% — кнопка «Что делать».
Обоснование из данных: ALL 8 агентов назвали это фичей №1. Оба синтеза подтвердили. >40 комментариев в Видео 1 + 80% GAP MAP в Видео 2 = буквально самый запрашиваемый функционал.
Фича 2: «Маршрутная карта ремонта» — приоритизированный чеклист
Что: Если светофор жёлтый или красный — кнопка «Что проверить» открывает пошаговый чеклист для конкретного двигателя. От бесплатных проверок (крышка горловины, щуп) к платным (ДМРВ, лямбда). С галочками «я уже это проверил» — каждый шаг сужает диагноз. С ценами: «Замена адсорбера: ~2000 руб. vs Перерасход: ~3000 руб./мес».
Почему закрывает 80%: Главная финансовая боль — перебор деталей вслепую (260К руб. впустую). «Куда копать?» — 25+ прямых запросов. Чеклист даёт то, что ни один сканер не даёт: ПОРЯДОК действий, не просто список возможных причин.
Обоснование из данных: ALL 8 агентов зафиксировали «слепой перебор». Кейс СТО-навязал-6-компонентов-причина-в-щупе — идеальная иллюстрация.
Фича 3: «Эталон для вашего двигателя» — сравнение с нормой
Что: Рядом с каждым параметром — столбец «Норма для [ваш двигатель]». Не абстрактные цифры, а конкретные: «Для Z18XER: ДМРВ на ХХ = 2.5-3.0 г/с. У вас: 4.1 — ЗАВЫШЕНО. Для K4M: LTFT норма ±7%. У вас: +6% — НОРМА.» С учётом модификаций (Евро-2, ГБО).
Почему закрывает 80%: Комментарий «Скиньте скрины исправного авто» — 18 лайков. Отсутствие эталона — корневая причина паники. Человек видит «+7%» и не знает, это проблема или нет. Сравнительная таблица решает это мгновенно.
Обоснование из данных: ALL 8 агентов. Оба синтеза назвали «убийственной фичей». Запрос эталонных значений — один из самых частых паттернов.

### 7. ЧТО НЕ ПОДТВЕРДИЛОСЬ

7.1. «Тревожный новичок с горящим чеком» — ЧАСТИЧНО ОПРОВЕРГНУТО
Исходная гипотеза предполагала, что пользователь — новичок в панике. Данные показывают: это человек с 2-12 месяцами опыта борьбы с проблемой, уже имеющий инструменты. Паника прошла, осталась хроническая фрустрация. Маркетинг должен говорить не «не паникуй», а «хватит мучиться». Но: 40% аудитории Видео 2 — действительно новички. Значит, сегмент «новичок с чеком» существует, но он не доминирующий.
7.2. «LLCAR как сканер» — ОПРОВЕРГНУТО
Позиционирование «OBD-II сканер с человеческим языком» не работает для этой аудитории. У них УЖЕ ЕСТЬ сканер. Им не нужен ещё один. LLCAR — не сканер, а интерпретатор. Это принципиально меняет конкурентное поле: конкурент — не CarScanner, а YouTube-блогеры и комментарии-форумы.
7.3. DTC-расшифровка как core feature — ПОД СОМНЕНИЕМ
Исходная гипотеза: расшифровка кодов ошибок — главная ценность. Данные: главная ценность — интерпретация LIVE-параметров (коррекция, ДМРВ, лямбда), а не кодов. Массовый феномен «неисправность без ошибки» — ДМРВ врёт, но ошибки нет. LLCAR должен анализировать тренды параметров в реальном времени, а не только DTC.
7.4. Медицинская метафора в интерфейсе — ПОД СОМНЕНИЕМ
Медицинская метафора хороша для структуры (Health Score, сертификат), но тон интерфейса должен быть гаражным, не клиническим. Аудитория ценит «давай разберёмся», а не «диагноз: нарушение адаптации». Структура — медицинская, голос — товарищеский.
7.5. Подписка как основная модель — ПОД СОМНЕНИЕМ
60%+ аудитории приходят с одной конкретной проблемой. Подписка пугает людей, которые хотят решить одну задачу и уйти. Для H1 (Trust Gap) — разовая оплата. Подписка — только для H2 (мониторинг), и только после демонстрации ценности мониторинга.

### 8. СЛЕДУЮЩИЕ ВОПРОСЫ — что 2256 комментариев НЕ ответили

1. Конверсия из бесплатного в платное. Люди готовы платить 349 руб. — но за ЧТО конкретно: за PDF-отчёт? За расшифровку скриншота? За полный анализ? Нужен A/B-тест paywall.
