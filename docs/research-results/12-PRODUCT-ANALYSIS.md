# 1. АРХИТЕКТУРА ПРОДУКТА А -- МОБИЛЬНОЕ ПРИЛОЖЕНИЕ

## 1.1 Философия мобильного продукта

Мобильное приложение -- это "карманный врач", который решает задачу В МОМЕНТЕ. Ключевое ограничение: пользователь находится в стрессе (поломка, чек, странный звук) или в спешке (перед поездкой, перед СТО). Интерфейс должен давать ответ за 30 секунд, а не требовать 10 минут изучения дашборда.

Из исследований: "Пользователь не хочет учиться ремонтировать машину -- он хочет быть уверенным, что с ней все в порядке, или точно знать, что делать при сбое" (01-custdev2-report, ключевой инсайт).

## 1.2 Экраны и табы

### Таб 1: ЗДОРОВЬЕ (Health) -- главный экран

**Что видит пользователь:**
- Health Score 0-100 (большое число + цвет: зеленый/желтый/красный)
- Статус одной фразой: "Все в порядке" / "Есть вопросы" / "Требует внимания"
- Индикатор "БЕЗОПАСНО ЛИ ЕХАТЬ" -- первая строка (инсайт I-4, 6/8 агентов YouTube, ни одно приложение не отвечает на этот вопрос)
- Система по блокам: Двигатель / Тормоза / Трансмиссия / Электрика -- флаги без деталей в free
- Кнопка "Провести диагностику" (одна, по центру)

**Логика монетизации:**
- Free: число Health Score + флаги систем + коды ошибок (без расшифровки)
- 349 руб.: полная расшифровка DTC + "безопасно ли ехать?" + рекомендация + PDF
- 1990 руб./год: безлимит + история + уведомления

### Таб 2: ОШИБКИ (DTC)

**Что видит пользователь:**
- Список обнаруженных кодов (P0420, P0171 и т.д.)
- Для каждого кода: расшифровка на ЧЕЛОВЕЧЕСКОМ языке ("Катализатор теряет эффективность")
- Светофор срочности: можно ехать / осторожно / в СТО сегодня / нельзя ехать
- Вероятные причины (отсортированы от дешевой к дорогой -- "Маршрутная карта ремонта")
- Ориентировочная стоимость ремонта
- Кнопка "СТОП -- проверь сначала" (инсайт I-6: крышка маслозаливной -> щуп -> дроссель, ПРЕЖДЕ чем менять лямбду)

### Таб 3: ТО-ЩИТ

**Что видит пользователь:**
- ДО визита: чек-лист обязательных работ по регламенту + данные OBD ("промывка инжектора НЕ НУЖНА -- LTFT в норме")
- ВО ВРЕМЯ визита: скрипты вопросов для механика, красные флаги "развода"
- ПОСЛЕ визита: загрузка фото сметы -> анализ: обязательное / сомнительное / навязанное
- Потенциальная экономия в рублях

### Таб 4: ПРОФИЛЬ АВТО

**Что видит пользователь:**
- Марка/модель/год/двигатель/пробег
- Контекст: Евро-2? ГБО? Кат удален? (критично для точности -- инсайт I-5)
- История сканирований (платная функция)
- Напоминания о ТО (8 из 12 информантов группы 13-24 назвали это главной фичей)
- Логбук обслуживания (ручной ввод + фото заказ-нарядов)

### Дополнительные экраны

- **Онбординг:** 3 иллюстрации (вставь адаптер / включи зажигание / нажми "подключить"). Первый экран: "LLCAR только читает данные. Как термометр -- не меняет ничего в машине" (страх "сломать машину" -- подтвержденный барьер)
- **Экстренный экран (SOS):** чек-лист действий при аварии, вызов эвакуатора, ближайшие сервисы на карте
- **Шаринг отчета:** красивый брендированный PDF для механика / покупателя / друга

## 1.3 User Flow по сегментам

### НОВИЧОК (14% выборки -- инф. 9, 13, 14, 27, 30)

**Контекст:** Стаж 1-3 года, первая машина (б/у), нет технических знаний, первая реакция при поломке -- звонок маме/папе/МЧ.

**Flow:** Загорелся чек -> паника -> открыл LLCAR -> увидел Health Score 67/100 + "1 ошибка" -> нажал "Узнать что значит" (349 руб.) -> увидел "Свечи зажигания, стоимость ~3000 руб., можно ехать, запишитесь в сервис на этой неделе" -> ПОНЯЛ, ЧТО ДЕЛАТЬ -> поделился PDF с папой.

**Ключевые потребности:**
- Без технического жаргона ("бампер, а не губа" -- инф. 30)
- Визуализация: цветовая индикация, схема авто (инф. 4, 20, 33)
- Расшифровка значков приборной панели по фото (инф. 13)
- Экстренные чек-листы: "попал в аварию -- что делать пошагово" (инф. 13)
- Офлайн-доступ (инф. 5, 23, 29, 33, 36)

**Частота:** Ситуационно (1-2 раза в месяц). Подписка маловероятна -- разовые платежи.

### ДЕЛЕГАТОР (51% выборки -- инф. 4, 8, 16, 17, 19, 22, 32, 35)

**Контекст:** Не хочет вникать. Цель -- передать машину профессионалу и получить обратно. Главная боль -- страх обмана в СТО.

**Flow:** Едет на ТО -> открыл LLCAR -> сгенерировал ТО-щит -> приехал в сервис С КОНКРЕТНЫМ ЗАПРОСОМ -> механик предложил "промывку инжектора за 4500" -> открыл отчет: "LTFT +3.2%, промывка НЕ НУЖНА" -> отказался -> СЭКОНОМИЛ 4500 руб.

**Ключевые потребности:**
- Защита от обмана ("адвокат против автосервиса" -- главный драйвер)
- Видеосвязь с мастером (инф. 16: "Позвонить по видеосвязи, и мастер такой: поднеси поближе к двигателю")
- Рекомендации проверенных СТО с лицензиями (инф. 28: "руками-ногами оторвала бы")
- Напоминания о ТО привязанные к пробегу/сезону
- Простой язык, ненавязчивый интерфейс (инф. 16: "как Самокат, а не Яндекс.Доставка")

**Частота:** Перед ТО (2-4 раза в год) + перед дальними поездками. Готовы к годовой подписке.

### ЭНТУЗИАСТ (29% выборки -- инф. 1, 3, 12, 25, 26, 29)

**Контекст:** Читает Drive2, имеет ELM327, пробовал CarScanner/Torque. Знает индекс двигателя. Чинит сам что может.

**Flow:** Коррекция -15% на CarScanner -> не понимает -- это нормально? -> загрузил скриншот в LLCAR (OCR -> LLM) -> получил: "Для Z18XER с Евро-2 это пограничная зона. Проверь сначала: 1) клапан адсорбера 2) ДМРВ (тест отключением) 3) лямбду. НЕ МЕНЯЙ лямбду пока не проверишь адсорбер" -> пошел проверять.

**Ключевые потребности:**
- Эталонные значения для своего двигателя ("покажите здоровую машину" -- 18 лайков на YouTube)
- Глубокая диагностика всех систем, не только ECU (инф. 1, 12)
- Связка: ошибка -> описание -> местоположение датчика -> мануал по замене -> где купить запчасть (инф. 27, 29)
- Комьюнити по маркам (инф. 25: "что-то как Strava, OpenRoad")
- Офлайн-доступ (инф. 29: "загрузить заранее, как карты")
- Красивый современный интерфейс (инф. 29, 30: "не 2010 года дизайн")

**Частота:** 1-2 раза в месяц при проблемах, но активно в комьюнити. Скорее freemium + разовые платежи за отчеты.

# 2. АРХИТЕКТУРА ПРОДУКТА Б -- ВЕБ-ДАШБОРД

## 2.1 Философия веб-дашборда

Веб-дашборд -- это инструмент ГЛУБОКОГО ПОГРУЖЕНИЯ, который не дублирует мобильное приложение, а расширяет его. Если мобильное отвечает на вопрос "Что с моей машиной сейчас?", то веб отвечает на вопросы "Почему так?", "Как это менялось?", "Лучше или хуже других?", "Что будет дальше?".

**Целевая аудитория веб-дашборда:**
- Энтузиасты, которые хотят разобраться "почему это сломалось" (инф. 29)
- Делегаторы с высокой платежеспособностью, которые хотят "доказательную базу" перед СТО
- Покупатели б/у авто (pre-purchase inspection)
- Продавцы авто (сертификат состояния)

## 2.2 Блоки веб-дашборда

### Блок 1: АГРЕГАЦИИ ПО МОДЕЛИ

**Что показывать:**
- "Ваш LTFT +7% -- среднее для Toyota Camry 2018 с пробегом 80-90K: +4%. Вы в диапазоне нормы, но выше среднего"
- Гистограммы распределения ключевых параметров для машин этой модели/года/пробега
- Перцентиль: "Ваша машина лучше, чем 72% аналогичных" (инсайт из 02-strategy-docs, Health Score)
- "Типичные значения для вашего двигателя Z18XER на ХХ: ДМРВ 2.5-3.0 г/с, LTFT +-5%"

**Источник данных:** Агрегированные анонимизированные данные всех пользователей LLCAR с таким же авто.

**Почему важно:** "Скиньте таблицу как должно правильно работать / скрины исправного авто" -- 18 лайков, самый запрашиваемый контент на YouTube. Инф. 25: "Интересно было бы посмотреть, в каком состоянии машины у других с такой же маркой."

### Блок 2: ЗАВИСИМОСТИ И ТРЕНДЫ

**Графики и корреляции:**
- **Температура от времени суток/сезона:** Coolant Temp тренд за 6 месяцев -- видно, когда термостат начал деградировать
- **Коррекция от пробега:** LTFT тренд: "на 120К было +3%, на 150К стало +8% -- деградация топливной системы"
- **Расход от стиля вождения:** средний расход по месяцам с наложением на пробег и сезон
- **Напряжение АКБ от температуры:** прогноз: "при -15C ваш аккумулятор может не завестись"
- **Пропуски зажигания по цилиндрам:** тренд за последние 10 сканирований -- видно, какой цилиндр деградирует

**Почему важно:** Из YouTube: пользователи мучаются с "плавающими" ошибками (инф. 25: "Проблема проявлялась только на морозе, стучала. Симптомы исчезали после прогрева"). Тренды ловят то, что одноразовое сканирование пропускает.

### Блок 3: ФОРМУЛЫ И ПРАВИЛА ДИАГНОСТИКИ

**Что показывать:**
- Дерево диагностики для каждого кода: P0171 -> подсос воздуха (60%) -> ДМРВ (25%) -> лямбда (10%) -> форсунки (5%)
- Таблица интерпретации LTFT с поправками на Евро-2/ГБО/удаленный кат (из 08-youtube-synthesis)
- Маршрутная карта ремонта: отсортированный чек-лист от бесплатного к дорогому
- Объяснение связей: "Почему грязный ДМРВ вызывает повышенный расход? Потому что ECU получает заниженный MAF -> обедняет смесь -> LTFT растет -> ECU компенсирует -> расход растет"
- Калькулятор потерь: "Ваша коррекция +15% стоит вам ~3400 руб./мес в перерасходе топлива" (инсайт I-14)

**Почему важно:** "Объяснение важнее данных" -- подтверждено из 5 независимых источников (I-2). 80%+ комментариев на YouTube = "моя коррекция X%, это нормально?"

### Блок 4: СОБЫТИЯ ПОЛЬЗОВАТЕЛЯ

**Что показывать:**
- Timeline: "Замена масла 15.01.2026 -> как изменился LTFT через 1000 км?"
- "Замена свечей 01.02.2026 -> пропуски зажигания снизились с 45/1000 до 2/1000"
- "Заправка на АЗС X -> резкий скачок STFT" (корреляция с качеством бензина)
- "Чистка ДМРВ 10.03.2026 -> MAF вернулся к норме, LTFT снизился с +12% до +4%"
- Сравнение ДО/ПОСЛЕ ремонта: "Стало ли реально лучше?" (из 02-strategy-docs, ситуация "врачебная ошибка" #4)

**Почему важно:** Инф. 18 (автомеханик): "Есть знакомые, которые могут проездить 20 тысяч км без замены масла." Визуализация последствий = мотивация к действию.

### Блок 5: БОЛЯЧКИ МОДЕЛИ

**Что показывать:**
- "Типичные проблемы Toyota Camry XV50 с пробегом 80-120К: 1) Цепь ГРМ (12% владельцев) 2) Катализатор (8%) 3) Жор масла 2AR-FE (15%)"
- Для каждой болячки: симптомы + какие параметры OBD мониторить + стоимость ремонта
- Отзывные кампании по VIN
- "Что пишут в интернете vs что показывают данные" (из 02-strategy-docs, ситуация 4: "эти моторы сыпятся")
- Персонализированная оценка рисков: "Риск проблем с цепью в ближайшие 30К км: НИЗКИЙ (15%)"

**Почему важно:** Инф. 22 (Виталий): "детская болячка Renault Scenic -- патрубок охлаждающей жидкости". Пользователи УЖЕ ищут болячки на Drive2/форумах. LLCAR дает персонализированную оценку вместо общей статистики.

### Блок 6: ШУМЫ, ВИБРАЦИИ, ТОРМОЖЕНИЕ

**Что показывать из данных акселерометра (173K записей):**
- Спектрограмма вибраций: норма vs отклонение (частотный анализ)
- Тренд вибраций по времени: "вибрация на холостых выросла на 15% за месяц -- возможно, износ подушек двигателя"
- Профиль торможения: средняя дистанция до остановки, резкость торможений
- Карта "тряски" по маршрутам (где дорога убивает подвеску)

**Что показывать из аудио-данных (85K записей):**
- Базовый шумовой профиль двигателя: норма vs текущее
- Детекция аномальных звуков: стук, скрип, свист
- Тренд шумности: "двигатель стал громче на 8% за 3 месяца на определенных оборотах"

**Что показывать из ECU (25K записей):**
- Мульти-ECU диагностика: двигатель + ABS + SRS + трансмиссия + климат
- Freeze Frame данные: "снимок момента приступа"
- Readiness Monitors: какие тесты пройдены, какие нет

**Почему важно:** Инф. 10 (Евгений): "Вы отталкиваетесь только от электронной системы, а механическую часть? Характерные звуки, скрипы, люфты -- это тоже важно." Акселерометр и аудио закрывают то, что OBD не видит.

## 3.1 Какие корреляции строить

## 3.2 Приоритеты по ценности

**P0 (MVP веб-дашборда):**

# 5. USER STORIES -- 10 ИСТОРИЙ ИЗ ИНТЕРВЬЮ

### US-1: "Юлия и мертвый аккумулятор" (инф. 14)

**История:** Машина заглохла на дороге. Стояла 5 часов. Случайный прохожий прикурил -- не помогло. Звонила маме. Вызвали знакомого -- приехал с новым аккумулятором.

**Как решает LLCAR Mobile:** Push-уведомление за 2 недели: "Напряжение АКБ 11.8V -- аккумулятор слабеет. Рекомендуем проверить/заменить до холодов." Если уже встала: SOS-экран с чек-листом + кнопка вызова эвакуатора.

**Как решает LLCAR Web:** Тренд Battery Voltage за 6 месяцев: видно постепенную деградацию. Прогноз: "При температуре -10C ваш АКБ не заведет машину с вероятностью 73%."

### US-2: "Дарья и обман в СТО" (инф. 32)

**История:** Привезла машину на ТО. Сказали менять колодки. Папа посмотрел: "Еще минимум год-два." Страх: "Дурят девушек."

**Как решает LLCAR Mobile:** ТО-щит перед визитом. После визита: загружает фото сметы -> LLCAR сравнивает с данными OBD: "Тормозные колодки: данных OBD о износе нет, запросите замер толщины штангенциркулем (норма >3мм). Если мастер не показал замер -- это красный флаг."

**Как решает LLCAR Web:** Сравнение: "Средний пробег до замены колодок на Mazda: 45-60К км. Ваш пробег после последней замены: 25К км. Вероятность необходимости замены: НИЗКАЯ."
