# Стандартизированные пороги вибрации компрессора (ISO/ГОСТ) для диагностики на автомобиле — возможно ISO 10816-3, но не п

**Slug:** `стандартизированные-пороги-вибрации-компрессора-isoгост-для-диагностики-на-автом` · **Категория:** `scientific-evidence` · **Evidence-only: peer-reviewed / standards / OEM bulletins**

## Описание

Стандарты серии ISO 10816 (и заменяющая ISO 20816) задают пороговые значения вибрации для промышленных машин, включая компрессоры, но не разрабатывались для автомобильных пневмокомпрессоров. Для группы 2 (15–300 кВт, жёсткий фундамент) ISO 10816-3 определяет границы зон A/B на уровне 2,8 мм/с RMS, B/C — 7,1 мм/с, C/D — 11,2 мм/с. Прямое применение этих порогов к автомобильным компрессорам ограничено из-за иных условий монтажа, оборотов и спектрального состава вибрации.

Специфические пороги для автомобильных компрессоров HVAC или пневмотормозов в стандартах ISO/ГОСТ не найдены. OEM-производители используют внутренние критерии, основанные на订单ных спецификациях, а не на открытых стандартах. Адаптация ISO 10816 к мобильным машинам дискутируется в литературе, но консенсуса нет.

## Claims (с уровнем доказательности)

- **[C]** ISO 10816-3:2009 устанавливает зоны вибрации для промышленных компрессоров группы 2 (15–300 кВт, жёсткий фундамент): зона A ≤ 2,8 мм/с RMS (хорошо), зона B ≤ 7,1 мм/с (приемлемо), зона C ≤ 11,2 мм/с (требует внимания), зона D > 11,2 мм/с (опасно).
  - Cites: ISO 10816-3:2009
  - Caveats: Пороги относятся к стационарным промышленным машинам; не валидированы для автомобильных компрессоров с иными частотами вращения и путями передачи вибрации.
- **[C]** ISO 20816-1:2016 заменяет ISO 10816 для новых машин, вводя уточнённые критерии и допуская адаптацию порогов для конкретных применений через соглашение между изготовителем и заказчиком.
  - Cites: ISO 20816-1:2016
  - Caveats: Не содержит автомобильных спецификаций; адаптация требует дополнительных исследований.
- **[D]** Прямые стандартизированные пороги вибрации для автомобильных пневмокомпрессоров (тормозных систем, подвески) в ISO/ГОСТ отсутствуют; производители используют внутренние NVH-спецификации.
  - Cites: SAE 2019-01-1548
  - Caveats: Основано на обзоре практики OEM; нет единого公開но доступного стандарта.
- **[D]** Для автомобильных компрессоров кондиционера (HVAC) вибрационные критерии обычно устанавливаются на уровне < 0,5–1,0 мм/с RMS на корпусе компрессора в диапазоне 10–1000 Гц, что значительно ниже порогов ISO 10816-3.
  - Cites: DOI:10.4271/2005-01-2534
  - Caveats: Значения из разрозненных SAE-публикаций; не закреплены в стандартах.

## Key formulas

- **Среднеквадратичное значение виброскорости (RMS)**: `v_rms = sqrt((1/T) * ∫₀ᵀ v²(t) dt)` (variables: v(t) — мгновенная виброскорость, T — период измерения, src: ISO 10816-3:2009)
- **Границы зон вибрации (компрессоры, группа 2, жёсткий фундамент)**: `Zone A: v_rms ≤ 2,8 мм/с; Zone B: ≤ 7,1 мм/с; Zone C: ≤ 11,2 мм/с; Zone D: > 11,2 мм/с` (variables: v_rms — RMS виброскорости в мм/с, src: ISO 10816-3:2009, Table B.1)

## Contradictions in literature

- **Применимость ISO 10816 к мобильным/автомобильным компрессорам** — PoV A: ISO 10816-3 может быть адаптирован для оценки вибрации автомобильных компрессоров с корректирующими коэффициентами.; PoV B: ISO 10816 прямо заявляет неприменимость к транспортным средствам и мобильным машинам; требуются отдельные стандарты.; resolution: ISO 20816-1:2016 расширяет возможности адаптации через машинные соглашения, но специфичные автомобильные пороги не установлены.
