## Описание

Платформа Audi MLB-evo (Modularer Längsbaukasten evolution) используется в моделях A4 B9, A5 F5, Q5 FY и других с многорычажной подвеской. NVH-оптимизация данной подвески включает гидравлические сайлент-блоки, пневматические амортизаторы и активные компоненты. Однако конкретные SAE Technical Papers, посвящённые именно NVH-исследованиям подвески MLB-evo, в открытой peer-reviewed литературе не обнаружены — OEM-исследования Volkswagen/Audi обычно остаются внутренними.

В открытой литературе доступны общие методологии NVH-анализа многорычажных подвесок премиум-сегмента и отдельные работы по компонентам подвески Audi/VW без привязки к конкретной платформе. Для получения специфичных SAE-номеров требуется прямой поиск по SAE International Mobility Database с фильтром по авторам из Audi/VW.
