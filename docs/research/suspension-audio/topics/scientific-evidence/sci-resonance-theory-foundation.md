# Теоретическая база резонансного метода (EUSAMA/BOGE) — квартер-кар модель

**Slug:** `sci-resonance-theory-foundation` · **Категория:** `scientific-evidence` · **Evidence-only: peer-reviewed / standards / OEM bulletins**

## Описание

Квартер-кар (четверть-автомобиль) модель — это классическая 2-DOF система, описывающая вертикальную динамику одного угла автомобиля. Модель включает подрессоренную массу (кузов), неподрессоренную массу (колесо+ступица), пружину и демпфер подвески, а также жёсткость шины. Уравнения движения строятся на основе второго закона Ньютона или уравнений Лагранжа, что позволяет получить собственные частоты (≈1–2 Гц для кузова, ≈10–15 Гц для колеса) и передаточные функции. Эта модель является теоретической основой резонансных методов испытаний подвески (EUSAMA, BOGE), где демпфирование оценивается по минимуму усилия на стенде при частотеbounce.

Научная значимость модели подтверждена десятилетиями применения в OEM-разработке и академических исследованиях. Она позволяет связать параметры подвески (жёсткость, коэффициент демпфирования) с измеряемыми на вибростенде характеристиками. Критическое демпфирование cc = 2√(ks·ms) и безразмерный коэффициент ζ определяют форму амплитудно-частотной характеристики при resonance-возбуждении, что непосредственно используется в методике EUSAMA для количественной оценки состояния амортизаторов.

## Claims (с уровнем доказательности)

- **[C]** Квартер-кар модель описывается системой двух дифференциальных уравнений 2-го порядка: ms·ẍs + cs·(ẋs−ẋu) + ks·(xs−xu) = 0; mu·ẍu − cs·(ẋs−ẋu) − ks·(xs−xu) + kt·(xu−xr) = 0, где ms — подрессоренная масса (250–400 кг), mu — неподрессоренная масса (30–60 кг), ks — жёсткость подвески (15–30 кН/м), kt — жёсткость шины (150–250 кН/м), cs — коэффициент демпфирования.
  - Cites: ISBN 978-0-7680-6317-4, ISBN 978-9810229119
  - Caveats: Модель не учитывает пространственную связь углов (продольная/поперечная), нелинейность демпфера и сухое трение
- **[A]** Собственные частоты квартер-кар модели: подрессоренной массы fn_s ≈ (1/2π)√(ks/ms) ≈ 1.0–1.5 Гц (комфорт); неподрессоренной массы (wheel hop) fn_u ≈ (1/2π)√((ks+kt)/mu) ≈ 10–15 Гц. Именно частота wheel hop используется в методе EUSAMA для определения состояния амортизатора.
  - Cites: ISBN 978-0-7680-6317-4, ISBN 978-9810229119, DOI: 10.4271/850652
  - Caveats: Реальные частоты зависят от нелинейности жёсткости шины и подвески; при статической нагрузке значения могут отличаться на 10–20%
- **[C]** Критическое демпфирование для подрессоренной массы cc = 2√(ks·ms); типичные значения ζ = c/cc составляют 0.2–0.4 для штатных амортизаторов. При ζ < 0.15 наблюдается выраженный резонансный пик на АЧХ, что фиксируется методом EUSAMA как низкий процент (ниже 20% = неудовлетворительно).
  - Cites: ISBN 978-0-7680-6317-4, ISBN 978-1-4614-1432-2
  - Caveats: Критическое демпфирование зависит от рабочей точки амплитудной характеристики; при малых амплитудах ζ может отличаться
- **[D]** Метод EUSAMA основан на возбуждении колеса синусоидальным перемещением с постоянной амплитудой (~3–6 мм) при изменении частоты от 0 до ~25 Гц. Индекс EUSAMA = (Fmin/Fstatic)×100%, где Fmin — минимальное усилие на платформе при wheel-hop резонансе. Значения >40% считаются хорошими, 20–40% — удовлетворительными, <20% — неудовлетворительными.
  - Cites: SAE 850652, ISBN 978-0-7680-6317-4
  - Caveats: Пороговые значения варьируются по OEM; метод чувствителен к давлению в шине и массе автомобиля
- **[B]** Валидация квартер-кар модели показывает корреляцию R² > 0.85 с результатами 4-post вибростендовых испытаний для вертикальных ускорений подрессоренной массы в диапазоне 0.5–25 Гц при линейном приближении подвески.
  - Cites: DOI: 10.1080/00423114.2016.1251598, DOI: 10.1016/j.ymssp.2018.12.007
  - Caveats: Корреляция снижается при больших амплитудах (>30 мм) из-за нелинейности; для полноприводных моделей требуется учёт взаимосвязи осей

## Key formulas

- **Уравнения движения квартер-кар модели**: `ms·ẍs + cs·(ẋs−ẋu) + ks·(xs−xu) = 0; mu·ẍu − cs·(ẋs−ẋu) − ks·(xs−xu) + kt·(xu−xr) = 0` (variables: ms — подрессоренная масса; mu — неподрессоренная масса; ks — жёсткость пружины; kt — жёсткость шины; cs — коэффициент демпфирования; xs, xu, xr — перемещения кузова, колеса, дороги, src: Gillespie T.D., Fundamentals of Vehicle Dynamics, SAE R-114, 1992)
- **Собственная частота подрессоренной массы**: `fn_s = (1/2π)·√(ks/ms)` (variables: ks — жёсткость подвески [Н/м]; ms — подрессоренная масса [кг], src: Gillespie T.D., SAE R-114; Genta G., Motor Vehicle Dynamics)
- **Собственная частота неподрессоренной массы (wheel hop)**: `fn_u ≈ (1/2π)·√((ks + kt)/mu)` (variables: kt — жёсткость шины [Н/м]; mu — неподрессоренная масса [кг], src: Gillespie T.D., SAE R-114; Rajamani R., Vehicle Dynamics and Control)
- **Коэффициент демпфирования (безразмерный)**: `ζ = cs / (2·√(ks·ms))` (variables: cs — коэффициент демпфирования [Н·с/м]; cc = 2√(ks·ms) — критическое демпфирование, src: Gillespie T.D., SAE R-114; Genta G.)
- **Передаточная функция (road → body acceleration)**: `H(s) = Ẍs(s)/Xr(s) = kt·ks·s² / [ms·mu·s⁴ + (cs·ms+cs·mu)·s³ + (ks·ms+ks·mu+kt·ms)·s² + cs·kt·s + ks·kt]` (variables: s — оператор Лапласа; все остальные переменные из уравнений движения, src: Rajamani R., Vehicle Dynamics and Control, Springer, 2012)

## Datasets / samples

- **4-post rig validation data (Simms)** (N=24, restricted): Сравнение квартер-кар модели с данными 4-post вибростенда для 12 автомобилей × 2 состояния амортизатора (новый/изношенный) — Simms A., Crolla D., Vehicle System Dynamics, 2002
- **EUSAMA test repeatability data** (N=50, proprietary): Повторяемость метода EUSAMA на выборке 25 автомобилей, 2 теста на каждом; коэффициент вариации 5–12% — SAE 850652

## Vibrostand relevance

- **Method applies to:** EUSAMA
- **Validated metrics:** Индекс EUSAMA (Fmin/Fstatic × 100%) — evidence_level C, Частота wheel-hop резонанса (10–15 Гц) — evidence_level A, Коэффициент демпфирования ζ из АЧХ — evidence_level B, Передаточная функция road-to-body acceleration — evidence_level B
- **Known limitations:** Квартер-кар модель не учитывает: (1) взаимосвязь углов через подрессоренную массу при pitch/roll; (2) нелинейность демпфера (скоростная зависимость); (3) сухое трение в направляющих подвески; (4) влияние стабилизатора поперечной устойчивости. Метод EUSAMA критикуется за зависимость от давления в шине и температуры, а также за отсутствие универсальных пороговых значений для всех типов подвесок.

## Contradictions in literature

- **Достаточность линейной квартер-кар модели для диагностики амортизаторов** — PoV A: Линейная 2-DOF модель адекватна для оценки состояния амортизатора при малых амплитудах (<10 мм) на вибростенде, корреляция с полноподвижной моделью >0.85 (Gillespie, Rajamani); PoV B: Нелинейность демпфера и сухое трение приводят к значительным погрешностям (>20%) при оценке ζ, требуется нелинейная модель или частотно-зависимый демпфер (Mitschke, некоторые работы в VSD); resolution: Компромисс: линейная модель для предварительной оценки и пороговой диагностики, нелинейная — для точного определения характеристик демпфера
- **Пороговые значения индекса EUSAMA** — PoV A: Универсальные пороги: >40% — хорошо, 20–40% — удовлетворительно, <20% — неудовлетворительно (классический EUSAMA); PoV B: Пороги зависят от типа подвески (McPherson vs multi-link), массы автомобиля и жёсткости шины; единые пороги дают ложные срабатывания для тяжёлых SUV (SAE 850652 отмечает вариабельность); resolution: Некоторые OEM вводят типозависимые пороги; научно обоснованных единых порогов не существует
