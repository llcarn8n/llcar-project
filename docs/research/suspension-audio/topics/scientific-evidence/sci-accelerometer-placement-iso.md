# Стандарты размещения акселерометра — ISO 5347, ISO 16063, ISO 10816

**Slug:** `sci-accelerometer-placement-iso` · **Категория:** `scientific-evidence` · **Evidence-only: peer-reviewed / standards / OEM bulletins**

## Описание

Стандарты серии ISO 16063 (заменившие ISO 5347) регламентируют методы первичной и вторичной калибровки вибропреобразователей, включая требования к месту и способу крепления при верификации амплитудно-частотной характеристики. Серия ISO 10816 (переходящая в ISO 20816) определяет точки измерений на корпусах машин и допустимые уровни вибрации. Корректность монтажа (шпилька, воск, магнит, клей) и соотношение масс «акселерометр / объект» напрямую определяют достоверность результатов в полосе до 10–50 кГц.

## Claims (с уровнем доказательности)

- **[C]** Отклонение АЧХ из-за массы акселерометра пренебрежимо мало (<1 %), если масса датчика составляет менее 1/10 эффективной массы конструкции в точке крепости в рассматриваемой полосе частот (ISO 16063-1, п. 6.2).
  - Cites: ISO 16063-1:2005
  - Caveats: Для конструкций с низкой поверхностной плотностью (тонкие панели ~1 мм) правило 1:10 может быть недостаточно; требуется модальный анализ.
- **[A]** Шпилечное крепление обеспечивает верхнюю рабочую частоту до ~50 кГц (монтажная резонансная частота); магнитное крепление — до ~2–5 кГц; пчелиный воск — до ~10–15 кГц при температуре <40 °C.
  - Cites: 10.1115/1.2895676, ISO 5347-22:1997
  - Caveats: Значения зависят от шероховатости поверхности, момента затяжки шпильки и температуры.
- **[C]** ISO 10816-3:2009 задаёт точки измерений на корпусах подшипниковых опор для машин номинальной мощностью 15–300 кВт; измерения проводятся в трёх ортогональных направлениях (осевое, горизонтальное, вертикальное) на жёстких элементах конструкции.
  - Cites: ISO 10816-3:2009
  - Caveats: Для транспортных средств применяются адаптированные методики (ISO 2631, ISO 8002), а не прямой перенос 10816-3.
- **[B]** Сравнение MEMS-смартфонных акселерометров с пьезоэлектрическими IEPE-датчиками показало расхождение RMS-ускорения ≤6 % в полосе 0,5–200 Гц для автомобильных NVH-применений (N=8 дорожных условий).
  - Cites: 10.3390/s20061818
  - Caveats: Смартфоны не позволяют контролировать крепление по ISO; ограниченный частотный диапазон, отсутствие калибровки по ISO 16063.
- **[C]** Калибровка по методу сравнения (ISO 16063-21) обеспечивает погрешность ≤2 % в диапазоне 0,5–10 кГц при использовании эталонного преобразователя и синусоидального возбуждения.
  - Cites: ISO 16063-21:2003
  - Caveats: Для многоосевых акселерометров требуется отдельная верификация поперечной чувствительности (ISO 16063-31).

## Key formulas

- **Погрешность из-за массовой нагрузки**: `δ_f ≈ (m_a / m_eff) × 100%` (variables: m_a — масса акселерометра; m_eff — эффективная масса конструкции в точке установки на данной частоте, src: ISO 16063-1:2005)
- **Резонансная частота шпилечного крепления**: `f_m ≈ 1/(2π) × √(k_m / m_a)` (variables: k_m — жёсткость монтажного соединения; m_a — масса акселерометра, src: ISO 5347-22:1997)

## Vibrostand relevance

- **Method applies to:** shaker, general
- **Validated metrics:** АЧХ акселерометра (evidence_level: C, ISO 16063-21), Поперечная чувствительность (evidence_level: C, ISO 16063-31), Фазовая характеристика (evidence_level: C, ISO 16063-21)
- **Known limitations:** Стандарты ISO 16063 не регламентируют методики для многоосевых стендов (4-post); ISO 10816 разрабатывалась для стационарных машин, не для автомобильных подвесок.

## Contradictions in literature

- **Достаточность правила «масса датчика < 10% массы объекта»** — PoV A: ISO 16063-1 и учебники (Harris, 6th ed.) считают правило достаточным для большинства применений.; PoV B: Исследования модального анализа показывают, что для тонкостенных конструкций (автомобильные панели <2 мм) даже 1% массы датчика может смещать собственные частоты на >5% в диапазоне >5 кГц.; resolution: Рекомендация дополнять массовй критерий модальным анализом (Operational Modal Analysis) для частот >2 кГц на тонких конструкциях.
- **Пригодность смартфонов для диагностической вибрации** — PoV A: Ряд публикаций (Sensors MDPI, 2017–2022) демонстрируют корреляцию >0,94 с профессиональными датчиками в полосе 0,5–100 Гц.; PoV B: OEM и стандарты не признают смартфонные измерения из-за неконтролируемого крепления, отсутствия калибровки, температурного дрейфа MEMS.; resolution: Предлагаются адаптивные калибровочные алгоритмы с коррекцией по температуре, но стандартизация пока отсутствует.

## Unknowns (gaps in peer-reviewed evidence)

- Peer-reviewed сравнения OEM-пьезоакселерометров со смартфонами для частот >200 Гц (автомобильная подвеска, тормозной NVH) практически отсутствуют.
- Отсутствуют стандартизированные методики крепления MEMS-датчиков к кузовным панелям для воспроизводимых межлабораторных сравнений.
- Не найдены peer-reviewed публикации по валидации методов ISO 16063-21 на 4-post вибростендах для низкочастотного диапазона 0,5–20 Гц.
