# Шаровые опоры — модели усталости и научные данные по ресурсу

**Slug:** `sci-ball-joint-fatigue-models` · **Категория:** `scientific-evidence` · **Evidence-only: peer-reviewed / standards / OEM bulletins**

## Описание

Шаровые опоры автомобильных подвесок подвергаются комбинированному износу и усталостному нагружению в условиях возвратно-вращательного движения сферы относительно вкладыша. Основные механизмы деградации включают абразивный/адгезивный износ поверхности трения, усталость контактной зоны (fretting fatigue) и накопление радиального/осевого люфта. Научное моделирование опирается на теорию контактного взаимодействия Герца для сферических пар, модель износа Archard (и её модификации для переменных нагрузок), а также критерии многоосевой усталости (Dang Van, Findley) для прогнозирования зарождения трещин.

## Claims (с уровнем доказательности)

- **[A]** Модель Archard (V = K·Fn·s/H) применима для оценки износа шаровых опор при возвратно-вращательном движении; коэффициент износа K для пары «сталь–полимерный вкладыш (PTFE-компаунд)» типично составляет 1×10⁻⁶–5×10⁻⁵ в зависимости от смазки и температуры.
  - Cites: 10.1016/j.wear.2018.04.012, 10.1016/j.triboint.2019.04.035
  - Caveats: Модель Archard не учитывает третье тело (продукты износа), температурную деградацию полимера и эффект fretting при малых амплитудах.
- **[B]** Максимальное контактное давление Герца для типичной шаровой опоры (диаметр сферы 22–28 мм, нагрузка 5–15 кН) достигает 800–2500 МПа; при превышении ~2000 МПа для стальных пар начинается пластическое течение и ускоренный износ.
  - Cites: 10.1016/j.triboint.2017.03.024
  - Caveats: Реальное давление зависит от геометрического зазора, износа вкладыша и наличия смазки; аналитическое решение Герца — идеализация.
- **[D]** Усталостный ресурс шаровых опор при стендовых испытаниях с переменной амплитудой нагружения (блок-секрет типа CARLOS) составляет 0.5–3×10⁶ циклов до достижения критического люфта 0.3–0.5 мм для полимерных вкладышей.
  - Cites: SAE 2015-01-2354
  - Caveats: Разброс результатов значителен (коэффициент вариации до 2.0) из-за производственного разброса свойств полимерного вкладыша.
- **[B]** Критерий Dang Van (τ + α·p_max ≤ β) лучше коррелирует с усталостным разрушением шаровых опор при многоосевом нагружении, чем критерий S-N по эквивалентному напряжению, по данным FEA+экспериментальных валидаций.
  - Cites: 10.1016/j.ijfatigue.2016.05.033
  - Caveats: Валидация проведена на ограниченной выборке (N<30); требуется калибровка параметров α, β для конкретных материалов.
- **[D]** Прогрессирующий износ шаровой опоры коррелирует с ростом амплитуды вибрации в диапазоне 200–800 Гц при возбуждении через колесо; вибрационный метод позволяет обнаружить люфт ≥0.15 мм.
  - Cites: SAE 2020-01-1432
  - Caveats: Порог обнаружения зависит от типа подвески, массы автомобиля и метода возбуждения; стендовая воспроизводимость не полностью валидирована.

## Key formulas

- **Archard wear equation**: `V = K · Fn · s / H` (variables: V — объём износа (м³); K — безразмерный коэффициент износа; Fn — нормальная нагрузка (Н); s — путь скольжения (м); H — твёрдость мягкого материала (Па), src: 10.1016/j.wear.2018.04.012)
- **Hertzian max contact pressure (sphere-on-concave)**: `p_max = (6·Fe·R*⁻²/π³)^(1/3), где 1/R* = 1/R₁ - 1/R₂` (variables: Fe — эквивалентная нагрузка (Н); R₁ — радиус сферы; R₂ — радиус вкладыша; R* — эквивалентный радиус кривизны, src: 10.1016/j.triboint.2017.03.024)
- **Dang Van fatigue criterion**: `τ(t) + α·p_max(t) ≤ β` (variables: τ(t) — касательное напряжение; p_max(t) — максимальное гидростатическое давление; α, β — материальные параметры, определяемые из двух типов усталостных испытаний, src: 10.1016/j.ijfatigue.2016.05.033)
- **Wear depth from Archard (modified for oscillatory motion)**: `h = K · p · N · Δθ · R / H` (variables: h — глубина износа (м); p — контактное давление (Па); N — число циклов; Δθ — амплитуда угла поворота (рад); R — радиус сферы (м), src: 10.1016/j.triboint.2019.04.035)

## Vibrostand relevance

- **Method applies to:** EUSAMA, BOGE, 4-post, general shaker
- **Validated metrics:** амплитуда вибрации в диапазоне 200–800 Гц при_excitation через колесный центр (evidence_level: D), радиальный люфт (play) шаровой опоры по результатам вибро-импедансного метода (evidence_level: D), изменение момента трения по спектральному анализу (evidence_level: D)
- **Known limitations:** Ограниченная стандартизация методик вибрационной диагностики шаровых опор на подвеске автомобиля; влияние демпфирования шины и массы кузова на чувствительность; мало peer-reviewed публикаций с крупными выборками (N≥50) по вибро-методам.

## Contradictions in literature

- **Применимость модели Archard к возвратно-вращательному движению в шаровых опорах** — PoV A: Archard адекватно описывает износ при малых амплитудах качания (Δθ < 15°) с учётом модифицированного коэффициента K.; PoV B: При fretting-условиях (Δθ < 1°) доминирует механизм окислительного износа, не описываемый Archard; требуются модели fretting maps.; resolution: Гибридные модели, комбинирующие Archard для скольжения и fretting-wear maps для малых амплитуд, предложены в Tribology International (2019).
- **Вибродиагностика шаровых опор на автомобиле vs. стенд** — PoV A: Вибрационный метод на подвеске автомобиля (EUSAMA-тип) достаточен для обнаружения люфта ≥0.3 мм.; PoV B: Влияние шинного демпфирования и межосевых резонансов делает метод ненадёжным; предпочтителен прямой измеритель люфта.; resolution: SAE 2020-01-1432 предлагает комбинированный метод (вибрация + момент сопротивления повороту), но выборка мала (N=8).
