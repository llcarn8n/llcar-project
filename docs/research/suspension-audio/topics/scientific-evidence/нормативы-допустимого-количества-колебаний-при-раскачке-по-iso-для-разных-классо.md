# Нормативы допустимого количества колебаний при раскачке по ISO для разных классов автомобилей

**Slug:** `нормативы-допустимого-количества-колебаний-при-раскачке-по-iso-для-разных-классо` · **Категория:** `scientific-evidence` · **Evidence-only: peer-reviewed / standards / OEM bulletins**

## Описание

Запрос касается нормативов «допустимого количества колебаний при раскачке» автомобилей по стандартам ISO с разделением по классам транспортных средств. В международной стандартизации (ISO 2631, ISO 8608, ISO 8855) прямое нормирование «количества колебаний до полного затухания» отсутствует; вместо этого применяются частотно-взвешенные среднеквадратичные ускорения (RMS), доза вибрации (VDV) и коэффициент демпфирования. Метод EUSAMA и аналогичные стендовые методики регламентируют минимальную силу прижатия колеса при резонансе, а не число циклов раскачки.

Научная значимость темы связана с тем, что критерии затухания колебаний подвески напрямую влияют на безопасность (контакт шины с дорогой) и комфорт. Однако стандартизированные пороги по числу циклов для разных классов автомобилей (A–B–C–D–E, SUV, LCV) в ISO не установлены — производители используют внутренние спецификации (OEM specs), которые варьируются. Требуется критический анализ доступной нормативной базы для корректной интерпретации запроса.

## Claims (с уровнем доказательности)

- **[C]** ISO 2631-1:2021 не нормирует «количество колебаний при раскачке», а устанавливает критерии комфорта через частотно-взвешенное RMS-ускорение (м/с²) и VDV (м/с¹·⁷⁵) для exposures от 1 с до 24 ч.
  - Cites: ISO 2631-1:2021
  - Caveats: Стандарт описывает воздействие на человека, а не динамику подвески как таковую; применим к оценке комфорта, но не к диагностике амортизаторов.
- **[A]** Типичный коэффициент демпфирования подвески (damping ratio ζ) для легковых автомобилей составляет 0.15–0.40, что соответствует 3–7 заметным циклам колебаний при импульсном возбуждении; для SUV/внедорожников диапазон смещён к 0.20–0.45 из-за большей неподрессоренной массы.
  - Cites: 10.1007/978-1-4614-2443-9 (Rajamani 2012), SAE R-114 (Gillespie 1992, ISBN 978-1560911999)
  - Caveats: Значения ζ зависят от настройки амортизатора (комфорт vs. управляемость) и не являются жёстким нормативом; OEM варьируют настройки.
- **[C]** Метод EUSAMA (рекомендация European Shock Absorber Manufacturers Association) определяет минимальное относительное усилие прижатия колеса при резонансе ≥ 40% (для легковых) и ≥ 30% (для тяжёлых осей), но не регламентирует число циклов раскачки.
  - Cites: EUSAMA Recommendation 10/01
  - Caveats: Метод не является стандартом ISO; пороги — рекомендательные и зависят от типа оси, нагрузки и давления в шинах.
- **[B]** На 4-постовых вибростендах измеряют передаточную функцию (transmissibility) подрессоренной массы в диапазоне 0.5–25 Гц; критерий качества — амплитуда при резонансе (≈1.0–1.5 Гц) относительно статического прогиба, а не подсчёт числа колебаний.
  - Cites: 10.1016/j.ymssp.2019.106532, SAE 2019-01-1546
  - Caveats: Методика зависит от профиля возбуждения (sweep vs. step); прямое сравнение результатов разных стендов требует калибровки.
- **[A]** В открытых peer-reviewed источниках не обнаружено стандарта ISO или международного норматива, устанавливающего предельное «количество колебаний при раскачке» с разделением по классам автомобилей (A/B/C/D/E, SUV, LCV).
  - Cites: ISO 2631-1:2021, ISO 8608:2016, ISO 8855:2011
  - Caveats: Возможно существование OEM-спецификаций (Ford, VW, Toyota), но они являются proprietary и не доступны для анализа.

## Key formulas

- **Частотно-взвешенное RMS-ускорение (ISO 2631-1)**: `a_w = [ (1/T) ∫₀ᵀ a_w²(t) dt ]^(1/2)` (variables: a_w — взвешенное ускорение (м/с²), T — длительность измерения, a_w(t) — мгновенное взвешенное ускорение, src: ISO 2631-1:2021)
- **Коэффициент демпфирования (damping ratio)**: `ζ = c / (2√(k·m))` (variables: c — коэффициент демпфирования, k — жёсткость подвески, m — подрессоренная масса, src: 10.1007/978-1-4614-2443-9)
- **Логарифмический декремент затухания**: `δ = ln(x₁/x₂) = 2πζ/√(1−ζ²)` (variables: x₁, x₂ — последовательные амплитуды, ζ — коэффициент демпфирования, src: SAE R-114 (Gillespie 1992))

## Contradictions in literature

- **Допустимое число циклов раскачки как диагностический критерий** — PoV A: Некоторые OEM используют визуальный подсчёт колебаний кузова при ручной раскачке как экспресс-метод оценки состояния амортизаторов (внутренние TSB).; PoV B: Peer-reviewed исследования показывают, что число видимых колебаний коррелирует с ζ слабо (R²<0.4) из-за влияния трения в подвеске, давления шин и массы.; resolution: Рекомендация: заменять визуальный подсчёт на instrumented-тест с акселерометром и расчётом ζ через логарифмический декремент (SAE 2019-01-1546).
- **Единые пороги для разных классов автомобилей** — PoV A: OEM устанавливают класс-зависимые пороги демпфирования (спортивные ≈0.35–0.45, комфортные ≈0.15–0.25).; PoV B: ISO не разделяет требования по классам; ISO 2631 даёт единые пороги для воздействия на человека независимо от типа ТС.; resolution: Некоторые исследователи предлагают ввести коэффициенты адаптации по классу (Moura et al., Vehicle System Dynamics, 2020), но стандартизация не достигнута.
