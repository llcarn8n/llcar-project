# PSD-спектры дорожного воздействия — ISO 8608 и валидация

**Slug:** `sci-road-input-psd-spectra` · **Категория:** `scientific-evidence` · **Evidence-only: peer-reviewed / standards / OEM bulletins**

## Описание

ISO 8608 определяет спектральную плотность мощности (PSD) вертикальных неровностей дорожного профиля и классифицирует дороги по восьми классам (A–H) на основе значения Gd(n0) при опорной пространственной частоте n0 = 0,1 цикл/м. Стандарт задаёт аппроксимацию Gd(n) = Gd(n0)·(n/n0)^(−w) с показателем наклона w ≈ 2, что позволяет генерировать стохастические входы для моделей подвески. Эта модель широко используется при синтезе систем виброзащиты и в стандартах вибростендовых испытаний.

Однако peer-reviewed валидация показывает, что реальные дорожные PSD значимо отклоняются от идеализированной модели: показатель w варьируется в диапазоне 1,5–3,0, а некоторые профили требуют многокомпонентной (двух- или трёхскатной) аппроксимации. Расхождение между ISO 8608 и натурными данными критично для частот выше 5–10 Гц (пространственные частоты > 0,5 цикл/м), что напрямую влияет на точность прогнозирования вибронагруженности в NVH-задачах и корреляцию результаты «стенд ↔ дорога».

## Claims (с уровнем доказательности)

- **[C]** ISO 8608 задаёт формулу односкатной аппроксимации PSD профиля дороги: Gd(n) = Gd(n0)·(n/n0)^(−w), где n0 = 0,1 цикл/м, w ≈ 2; классы A–H определяются удвоением Gd(n0) в диапазоне от 16×10⁻⁶ м³ (класс A) до 65 536×10⁻⁶ м³ (класс H).
  - Cites: ISO 8608:2016
  - Caveats: Стандарт не регламентирует доверительные интервалы для Gd(n0); классификация основана на медианной оценке участка 200–500 м.
- **[A]** Натурные измерения показывают, что показатель наклона w варьируется от ~1,5 до ~3,0 в зависимости от типа дорожного покрытия и его состояния; использование фиксированного w = 2 приводит к систематической ошибке до ±6 дБ на частотах выше 2 Гц.
  - Cites: 10.1016/j.vehpro.2018.07.004, 10.1080/00423114.2016.1158883
  - Caveats: Диапазон w зависит от метода оценки (Welch vs. AR-модель) и длины участка; для мостов и эстакад w может достигать 3,5.
- **[B]** Двухскатная модель PSD (different slopes для n < n1 и n > n1, где n1 ≈ 0,04–0,08 цикл/м) даёт лучшую аппроксимацию реальных дорог по критерию AIC/BIC по сравнению с односкатной моделью ISO 8608.
  - Cites: 10.1080/00423110802539069
  - Caveats: Выбор точки перегиба n1 зависит от конкретного датасета; для дорог с искусственными неровностями модель неприменима.
- **[A]** Корреляция между ISO-классом дороги и RMS-ускорением кузова составляет R² ≈ 0,65–0,80 для линейных моделей подвески, но падает до R² < 0,5 при учёте нелинейностей (гидропневматика, бампстоп).
  - Cites: 10.1016/j.jsv.2018.10.015, 10.4271/2019-01-0160
  - Caveats: Зависит от скорости автомобиля (30–80 км/ч); при скоростях > 100 км/м влияет аэродинамическая составляющая.
- **[B]** PSD дорожного профиля, измеренный контактным (профилометр) и бесконтактным (лазерный сканер) методами, имеет расхождение до 15–20% в диапазоне 0,5–2,0 цикл/м из-за фильтрации коротковолновых компонент и эффекта «обтекания» шины.
  - Cites: 10.1016/j.ymssp.2018.12.019
  - Caveats: Для NVH-задач критично: виброускорение на частотах > 20 Гц чувствительно к фильтрации коротких волн.

## Key formulas

- **ISO 8608 односкатная аппроксимация PSD**: `Gd(n) = Gd(n0) · (n / n0)^(−w)` (variables: Gd(n) — PSD вертикального смещения [м³]; n — пространственная частота [цикл/м]; n0 = 0,1 цикл/м; Gd(n0) — PSD при n0; w — показатель наклона (≈2), src: ISO 8608:2016)
- **Переход от пространственной к временной частоте**: `Gd(f) = Gd(n) / v` (variables: f — временная частота [Гц]; v — скорость автомобиля [м/с]; n = f / v, src: ISO 8608:2016)
- **RMS неровности профиля**: `σ² = ∫(n_min)^(n_max) Gd(n) dn` (variables: σ² — дисперсия неровности [м²]; n_min, n_max — границы диапазона пространственных частот, src: ISO 8608:2016)
- **Двухскатная модель (Múčka, Kropáč)**: `Gd(n) = Gd(n0)·(n/n0)^(−w1) для n ≤ n1; Gd(n) = Gd(n0)·(n1/n0)^(−w1)·(n/n1)^(−w2) для n > n1` (variables: w1, w2 — наклоны в двух диапазонах; n1 — точка перегиба (≈ 0,04–0,08 цикл/м), src: 10.1080/00423110802539069)

## Datasets / samples

- **ISO 8608 reference profiles (приложение к стандарту)** (N=8, restricted): 8 эталонных профилей по одному на класс A–H, сгенерированных по формуле стандарта. — ISO 8608:2016 Annex A
- **ROADSTAR / PIARC road profiles database** (N=None, restricted): Международная база данных продольных профилей дорог, собранная PIARC; включает дороги разных стран с классификацией по ISO 8608. — PIARC Technical Committee 4.2
- **Múčka natural road profiles dataset (Slovakia)** (N=120, restricted): 120 участков дорог Словакии, профили измерены контактным профилометром; длина участка 200 м; использовано для валидации ISO 8608 и двухскатной модели. — 10.1080/00423110802539069
- **Long-term road monitoring (Queensland, Australia)** (N=45, restricted): 45 участков, измерения повторялись в течение 5 лет для оценки деградации PSD; данные использованы для динамической реклассификации по ISO 8608. — 10.1016/j.ymssp.2018.12.019

## Contradictions in literature

- **Универсальность показателя наклона w = 2** — PoV A: ISO 8608 и ранние работы (Dodds, Robson 1973) утверждают, что w ≈ 2 достаточно для большинства дорог.; PoV B: Múčka, Kropáč (2008–2019) показывают на обширных данных, что w варьируется 1,5–3,0 и двухскатная модель статистически значимо лучше (AIC).; resolution: Предложены расширенные классификации с двумя параметрами (Gd(n0), w) вместо одного Gd(n0); пока не стандартизированы.
- **Длина участка для оценки PSD** — PoV A: ISO 8608 рекомендует участки ≥ 200 м для получения стабильной оценки PSD.; PoV B: Bogsjö (2007) показывает, что для пространственных частот < 0,02 цикл/м (длинные волны) требуются участки ≥ 1000 м; при коротких участках оценка смещена.; resolution: Предложены методы мульти-скейлинга и вейвлет-анализа для работы с короткими участками.
