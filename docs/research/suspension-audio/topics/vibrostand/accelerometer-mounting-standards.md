# Стандарты монтажа акселерометра на подвеску

**Slug:** `accelerometer-mounting-standards` · **Категория:** `vibrostand` · **Priority:** 1

## Описание

Стандарты монтажа акселерометра на элементы подвески регламентируются ISO 5348 (заменил часть ISO 5347) и определяют три основных метода: резьбовой шпилькой (полоса пропускания до 30–50 кГц при моменте затяжки 2.5–5 Н·м), плоским магнитом (до 5–10 кГц на шлифованной поверхности) и клеевой/восковый (ограниченная температура и частота). Для мобильной диагностики через смартфон (MEMS-акселерометры типа Bosch BMA456, InvenSense ICM-42688) полоса ограничена 400–1600 Гц по ODR, что снижает требования к жёсткости крепления, но критично для ВЧ-дефектов подшипников.

На практике для подвески достаточно магнитного крепления на зачищенную до металла стальную поверхность (рычаг, кулак), при условии контроля частотного диапазона задачи. Для подшипниковых дефектов >3 кГц требуется шпилечный монтаж или специализированные MEMS с расширенной полосой. Смартфон применим для низкочастотных компонент: дисбаланс колёс (10–25 Гц), биение шин (≤80 Гц), люфты (≤300 Гц), но не заменяет промышленный пьезо-датчик для АЭ-диагностики.

## Симптомы

- **HIGH** — Завал АЧХ >5 кГц при магнитном креплении на ржавую/окрашенную поверхность _(Магнит на непрокатанную поверхность)_
- **HIGH** — Ложный резонанс крепления в рабочей полосе (400–800 Гц) _(Ослабленный магнит или прослабленная шпилька)_
- **MEDIUM** — Разброс амплитуды 20–30% при повторной установке _(Клеевой крепитель на неровной поверхности)_
- **MEDIUM** — Невозможность захвата сигнала >1 кГц _(MEMS смартфон с ODR 400 Гц (Android API ограничение))_
- **LOW** — Наводка 50 Гц и гармоники в сигнале _(Неподвижный кабель без разгрузки у пьезо-датчика)_
- **HIGH** — Сигнал отсутствует — магнит не держится _(Магнит на алюминиевом рычаге)_

## Expert sequence

1. **Определить частотный диапазон дефекта: подшипник 3–15 кГц, шина ≤80 Гц, люфт ≤500 Гц** — _Диапазон определяет метод крепления_  · tool: Техническая документация OEM
2. **Выбрать метод: шпилька (>10 кГц), магнит (≤5 кГц), MEMS смартфон (≤1.6 кГц)** — _Совместимость поверхности: сталь для магнита, резьба М5/М6 для шпильки_  · tool: Набор крепёжных аксессуаров
3. **Подготовить поверхность: зачистить до металла (RA ≤3.2 мкм), обезжирить** — _Проверка «на прихват» — датчик не должен сдвигаться вручную с усилием >20 Н_  · tool: Шлифшкурка P320, изопропиловый спирт
4. **Установить датчик в точку с ориентацией главной оси перпендикулярно поверхности** — _Проверить отсутствие зазоров (щуп 0.05 мм не проходит)_  · tool: Схема точек OEM, щуп
5. **Провести тестовую запись и проверить спектр на отсутствие артефактов крепления** — _Нет аномальных узких пиков на частоте резонанса крепления (магнит ~7 кГц, шпилька ~50 кГц)_  · tool: Анализатор спектра (осциллограф)

## Correlations with other defects

- **Резонанс подвески (амортизатор/пружина)**: Резонанс крепления — узкополосный пик, сдвигается при нажатии на датчик; подвесочный — широкий, зависит от скорости
- **Электромагнитная наводка (injector/alternator)**: Наводка исчезает при глушении двигателя, присутствует даже при неподвижном авто; артефакт крепления — только при вибрации
