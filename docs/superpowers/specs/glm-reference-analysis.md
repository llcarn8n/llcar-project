# GLM Reference Analysis — CyberDefend + EffiTrack

## Key patterns to apply (next session):

### From CyberDefend:
1. Dot-matrix background pattern (radial-gradient dots)
2. L-shaped corner brackets on panels (SVG)
3. Animated data stream connections (SVG particles on bezier paths)
4. LED node status indicators (pulsing dots per subsystem)
5. Holographic sheen on hover (conic-gradient rotation)
6. Thermal color scheme: cyan=normal, amber=stress, red=critical

### From EffiTrack:
1. Bento-grid asymmetric layout
2. Left-border accent cards (3px colored border-left)
3. Gradient fill SVG charts with glow
4. Compact status badges (pills)
5. Segmented filter controls
6. Metric cards: icon + label + large value + trend arrow

### Priority order:
1. Dot-matrix background + corner brackets (instant visual upgrade)
2. Left-border accent on instrument panels
3. Status badge pills for subsystems
4. Animated data connections (later, complex)
