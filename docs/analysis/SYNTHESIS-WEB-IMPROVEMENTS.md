## 1. Executive Summary: 5 ключевых инсайтов

### Инсайт 1: Веб-дашборд обслуживает НЕ ТУ аудиторию
Текущий дашборд (V3) -- HUD-стиль, 3D Digital Twin, CUSUM-графики -- ориентирован на **энтузиастов (29%)**. Но основная ЦА -- **делегаторы (51%)**, которым нужна "зеленая галочка", а не графики. На сайте отсутствует лендинг для массовой аудитории: нет простых объяснений, нет "безопасно ли ехать?", нет конверсионной воронки.

### Инсайт 2: Сайт не продает -- он демонстрирует
Все 5 документов сходятся: LLCAR монетизируется через **разовые отчеты (349 руб.)** и **подписку (499/мес)**. На сайте нет ни прайсинга, ни paywall, ни конверсионных элементов. Текущий веб-дашборд = бесплатная витрина, а не продающий инструмент.

### Инсайт 3: SEO -- упущенная золотая жила
Контент-стратегия прямо указывает: 500+ страниц DTC-каталога + 100+ страниц "болячек моделей" = массовый органический трафик. На сайте нет ни одной SEO-страницы. Текущий SPA (React) не индексируется поисковиками. Это критический пробел.

### Инсайт 4: Конкурентное позиционирование невидимо
Конкурентный анализ выявил 15+ уникальных функций LLCAR (сенсорная диагностика, Health Score, "безопасно ли ехать?", 103 правила, 36K DTC). На сайте нет ни одной страницы сравнения с CarScanner/Torque. Посетитель не понимает, чем LLCAR отличается.

### Инсайт 5: Нет B2B-входа
Стратегия продаж описывает 4 B2B-сегмента (СТО, дилеры, страховые, флит). На сайте нет ни одного B2B-элемента. Отдельный лендинг для СТО может дать ARPU 3 990 руб./мес vs 499 руб./мес у B2C.

## 2. Веб-улучшения из продуктового анализа

### 2.2 Изменения на лендинге (Landing.tsx)

Текущий лендинг -- экран выбора машины (VehicleSelect.tsx). Это **не продающий лендинг**, а технический стартовый экран.

**Нужно:**
1. **Hero-секция** с ключевым сообщением: "Ваш сканер показывает цифры. LLCAR объясняет, что они значат и что делать."
2. **Демо Health Score** -- интерактивная визуализация (светофор зеленый/желтый/красный) без подключения к авто.
3. **3 карточки JTBD**: "Загорелся чек?", "Едешь в СТО?", "Продаешь машину?" -- каждая ведет к соответствующему CTA.
4. **Социальное доказательство**: "36 102 кода ошибок", "999 моделей", "103 правила диагностики".
5. **Блок сравнения** "До/После": "СТО говорит: менять всё (50 000 руб). LLCAR показывает: менять свечи (800 руб)."
6. **CTA**: "Проверить бесплатно" (ведет на VehicleSetup) + "Скачать приложение" (RuStore/APK).
7. **Текущий VehicleSelect** переместить на второй шаг (после клика CTA).

### 2.3 Приоритеты фич для веб-версии

Из продуктового анализа (раздел 5.4 "НЕ делать"): **3D-графики для массовой аудитории НЕ нужны** (0/10 интервью). Текущий дашборд с 3D DigitalTwinCanvas.tsx, SmartSphere.tsx, CarWireframe.tsx -- это для энтузиастов. Для массовой аудитории нужен **упрощенный режим** без 3D.

**Рекомендация:** Добавить переключатель в Dashboard.tsx:
- **Простой режим** (делегаторы): Health Score + светофор систем + "безопасно ли ехать?" + маршрутная карта
- **Продвинутый режим** (энтузиасты): текущий HUD + 3D + CUSUM + корреляции

## 5. Веб-улучшения из контент-стратегии

### 5.1 Блог / раздел статей

**Критический пробел.** Контент-стратегия описывает 5 контентных столпов и детальный контент-календарь, но на сайте нет раздела для контента.

**Новая страница: Blog.tsx** (роут `/blog`)
- Статьи по 5 столпам: "безопасно ли ехать?", "цифровой адвокат", "переводчик с машинного", "болячки модели", "экономия и ТО"
- SSR/SSG обязателен для SEO (текущий React SPA не индексируется)
- Интеграция с YouTube: embed видео в статьях

**Реализация:** Рассмотреть Next.js или отдельный SSG (Astro/11ty) для контентных страниц. Текущий SPA (React + Vite) не подходит для SEO-контента.

### 5.2 SEO-страницы: DTC-каталог

**Самый высокоприоритетный SEO-проект.** Контент-стратегия: "500+ страниц DTC-каталога -- расшифровка каждого кода на русском с действиями."

На сайте уже есть:
- `ErrorCodes.tsx` (роут `/dtc`) -- страница поиска DTC
- `DTCSearch.tsx` -- компонент поиска

**Что нужно:**
1. **Индивидуальные страницы для каждого DTC**: `/dtc/P0300`, `/dtc/P0420`, `/dtc/P0171` и т.д.
2. Контент: расшифровка на русском + "безопасно ли ехать?" + маршрутная карта + стоимость ремонта + связанные коды
3. Структурированные данные (JSON-LD: FAQ, HowTo) для Google
4. Серверный рендеринг (SSR/SSG) -- без него Google не проиндексирует SPA
5. **Приоритет**: начать с топ-50 DTC из Knowledge Base (уже привязаны к 764 ситуациям)

**Оценка трудозатрат:** Средняя (M). Нужен SSR-слой + динамический контент из KB API.

### 5.3 SEO-страницы: каталог "болячек" по моделям

**Новый роут: `/models/:brand/:model`**

Контент-стратегия: "100+ страниц 'Болячек' по моделям -- типичные проблемы и решения."

На сайте уже есть:
- `VehicleInfo.tsx` (роут `/vehicle`) -- информация о выбранном авто
- `SpecCards.tsx` -- спецификации

**Что нужно:**
1. Публичные страницы по моделям (без авторизации): `/models/kia/rio`, `/models/haval/f7`
2. Контент: типичные проблемы, частые DTC, стоимость ТО, эталонные значения
3. CTA внизу: "Проверь свою [модель] -- бесплатно"
4. Данные: из KB (58 брендов, 999 моделей, brand-specific ситуации)

### 5.4 YouTube-интеграция на сайте

На сайте нет интеграции с YouTube. Нужно:

1. **Embed YouTube-видео** на страницах DTC-каталога и "болячек модели"
2. **Секция "Видео" на Landing.tsx**: "Смотри, как LLCAR работает" (ссылка на канал)
3. **Resources.tsx** (`/resources`): добавить раздел "Видеогайды" с embed плеером

## 6. Веб-улучшения из стратегии продаж

### 6.1 Страница прайсинга

**Критический пробел.** На сайте нет информации о ценах.

**Новая страница: Pricing.tsx** (роут `/pricing`)

Из sales-strategy.md (раздел 1):

| Тариф | Цена | Ключевое описание |
|-------|------|-------------------|
| Free | 0 | Health Score + статус систем + коды БЕЗ расшифровки |
| Разовый отчет | 349 руб | Расшифровка + "безопасно ли ехать?" + маршрутная карта + стоимость |
| Подписка мес | 499 руб/мес | Все + безлимит + история + тренды + ТО-уведомления |
| Подписка год | 2 990 руб/год | Экономия 40% + 2 PDF-сертификата |

**Дизайн прайсинга:**
- 3 колонки (Free / Отчет / Подписка) с выделением "Популярное" на подписке
- Якорь: "Диагностика в СТО: 3 000 руб. -> LLCAR: 349 руб."
- Блок "Окупаемость": "Потенциальная экономия на одной ситуации: до 10 500 руб."
- FAQ под прайсингом: "Зачем платить, если есть Drive2?" -> ответ из стратегии

### 6.2 Визуализация Freemium-тиров

В текущем дашборде (Dashboard.tsx, Diagnostics.tsx) все данные показаны без ограничений. Нужен paywall-механизм:

| Что видно бесплатно | Что за paywall |
|---------------------|---------------|
| Health Score (число + цвет) | Детализация по системам |
| Коды ошибок (список) | Расшифровка на человеческом языке |
| Светофор LTFT/STFT | Точные значения + норма по модели |
| 1 сканирование/день | Безлимитные сканирования |

**Файлы для изменений:**
- `DiagnosisCardV2.tsx` -- добавить paywall-blur на расшифровку/маршрутную карту
- `Diagnostics.tsx` -- кнопка "Расшифровать за 349 руб." после бесплатного скана
- `Dashboard.tsx` -- Health Score видим, детали систем -- blur + CTA
- Новый компонент: `PaywallOverlay.tsx` -- переиспользуемый blur + CTA + цена

### 6.3 Конверсионная воронка на вебе

Из sales-strategy.md (раздел 3):

```
Текущая воронка (ОТСУТСТВУЕТ на вебе):
Landing -> Онбординг (марка/модель) -> Первый скан -> Health Score (бесплатно)
```

**Нужно реализовать в App.tsx / Diagnostics.tsx:**

2. Условный рендеринг контента по состоянию
3. Оплата: интеграция с ЮKassa (СБП/МИР) или Robokassa
4. После оплаты: unlock контента + PDF-генерация

## 8. Кросс-документные противоречия и их разрешение

### Противоречие 1: Цена подписки

| Документ | Цена подписки/мес | Цена подписки/год |
|----------|-------------------|-------------------|
| product-analysis.md | 299 руб./мес | 1 990 руб./год |
| marketing-strategy.md | 249 руб./мес | 1 990 руб./год |
| sales-strategy.md | 499 руб./мес | 2 990 руб./год |
| competitive-analysis.md | 249 руб./мес | 1 990 руб./год (СНГ) |

**Разброс:** от 249 до 499 руб./мес, от 1 990 до 2 990 руб./год.

**Решение:** Sales-strategy наиболее обоснована (медиана WTP из CustDev2 = ~500 руб./мес). Использовать **499 руб./мес и 2 990 руб./год** как стартовые цены. A/B тестирование в первые 3 месяца. На Pricing.tsx показывать 499/мес с зачеркнутой ценой "год = 249/мес" (при годовой оплате).

### Противоречие 2: "Безопасно ли ехать?" -- бесплатно или за paywall?

| Документ | Позиция |
|----------|---------|
| product-analysis.md (5.1) | **БЕСПЛАТНО** -- "Безопасность за paywall = потеря доверия навсегда" |
| sales-strategy.md (3.2) | **За paywall** -- "Кнопка 'Безопасно ли ехать?' = paywall. Это P0-фича" |

**Решение:** Это критическое противоречие. Product-analysis прав: безопасность за paywall = репутационный риск + юридический риск. **Базовый ответ (да/нет + цвет) -- БЕСПЛАТНО.** За paywall -- детальное объяснение + маршрутная карта + стоимость ремонта. На Diagnostics.tsx: светофор "ехать можно / нельзя" виден всем, расшифровка "почему" -- за blur.

### Противоречие 3: Free-тир -- что включено?

| Документ | Free включает |
|----------|--------------|
| product-analysis.md | Health Score + "безопасно ли ехать?" + DTC 1-строчная расшифровка + **1 бесплатный полный отчет** |
| sales-strategy.md | Health Score + статус систем + коды БЕЗ расшифровки + 1 скан/день |
| competitive-analysis.md | Health Score + статус систем + коды БЕЗ расшифровки + светофор LTFT |

**Решение:** Product-analysis наиболее щедрый (включает 1 бесплатный отчет). Это правильная стратегия для снижения барьера: **1 бесплатный полный отчет** = пользователь видит ценность и конвертируется. На Pricing.tsx: "Первый отчет -- бесплатно. Последующие -- 349 руб."

### Противоречие 4: Кто приоритетнее -- энтузиасты или делегаторы?

| Документ | Приоритет Phase 1 |
|----------|-------------------|
| product-analysis.md | Энтузиасты (29%) -- ранние последователи, уже с ELM327 |
| marketing-strategy.md | Энтузиасты (Phase 1), Делегаторы (Phase 2) |
| sales-strategy.md | Делегаторы (51%) -- основная ЦА |

**Решение:** Противоречия нет. Для **приложения** Phase 1 = энтузиасты (им нужен ELM327). Для **сайта/лендинга** -- оба одновременно. Лендинг должен говорить на языке делегаторов (простота, "зеленая галочка"), но вести на дашборд для энтузиастов. **Два CTA на Landing.tsx:** "Проверить бесплатно" (web-дашборд) и "Скачать приложение" (мобильное для делегаторов).

### Противоречие 5: North Star Metric

| Документ | NSM |
|----------|-----|
| product-analysis.md | Количество платных диагностических отчетов в неделю |
| marketing-strategy.md | Количество "шеримых отчетов" в неделю |

**Решение:** Оба имеют смысл. "Шеримые отчеты" = подмножество платных + виральный эффект. Использовать **платные отчеты** как основной NSM, **шеримые** как secondary. На вебе: трекинг обоих через аналитику.
